# 归图标志

- `guitu.svg`：256 × 256 应用图标，深松绿色圆角底，用于应用入口及 Windows 图标。
- `guitu-header.svg`：透明底彩色标志，用于深色顶部栏，显示尺寸固定为 28 × 28 像素。
- `guitu.ico`：包含 16、20、24、32、40、48、64、128、256 像素的 Windows 图标，嵌入程序文件及 Qt 资源，用于文件图标、标题栏和任务栏。
- `guitu-mark.svg`：192 × 192 透明底单色标志，适合浅色背景和文档。

图形将“归”字与照片融合：左侧短竖化为向左倾斜 10° 的照片卡片，较宽的底部留白表现实体照片的纸边；长撇保留汉字轮廓，形成简洁的收拢弧线。右侧笔画形成向左开放的相框，框内以山峰与圆日传达图片含义。左侧长笔宽 24 单位，右侧相框厚 20 单位。主色为深松绿 `#163F3A`，字形与圆日为米白 `#F3F5E9`，山峰为浅绿 `#9BD8BB`。

SVG 仅使用矢量路径，没有字体、位图和外部依赖。等比例缩放，不拉伸；标志外围至少留出图形宽度的八分之一作为净空。应用图标建议最小显示尺寸为 24 × 24 像素。

`guitu.svg` 是彩色图标源文件。修改后运行 `.venv\Scripts\python.exe tools\build_brand.py`，生成顶部栏 SVG 和多尺寸 ICO；重新构建应用以更新嵌入的 Windows 图标。单色标志单独维护。
