# 图片编辑与子图归类

## 编辑交互

双击图片进入编辑工作区；视频进入播放器，Live Photo 提供静态编辑和动态播放入口。编辑保留当前目录与批次上下文，参数保存为草稿，不覆盖原图。

- 裁剪比例支持自由、原图、1:1、4:3、3:2、16:9、自定义及保存预设；可切换横竖比例。
- 裁剪框内部可拖动移动，四角及四条边均可拖动缩放。四条边中央显示短线手柄，整条边提供命中区域，角点优先响应。自由比例时边拖动仅改变对应方向；固定比例时固定对边，并围绕另一方向的中心对称调整。比例约束形状，默认不放大小裁剪区域或强制缩放成固定尺寸。
- 平移碰到图片边界时，仅限制越界方向，仍可沿边移动，旋转图片沿其实际边界约束。框内移动、边和角缩放均不累积被拒绝的鼠标位移，反向拖动立即响应，无需先把鼠标移回边界。
- 旋转支持任意角度输入与拖动微调，默认步长 0.1 度，提供网格参考线及左右 90 度快捷旋转。
- 拖动旋转滑块时持续更新画面，不等待鼠标松开；输入有效角度立即预览。预览复用已解码图片，裁剪框与旋转画布同步更新，草稿写入独立延后合并，松开滑块时保存。
- 旋转后显示有效图像区域，裁剪框默认限制在实际图像四边形内。旋转时收紧越界区域，四角、四边缩放及框内平移均受边界约束；固定比例保持不变。预览与导出使用相同变换定义，导出另核对像素取整后的四角。原图自身的透明像素不视为几何越界。保留整幅旋转图像时需显式选择透明或背景填充，此模式属于独立功能。
- 默认以 aspectFit 完整展示图片；在图片上双击按当前旋转画布的宽高比放大至 aspectFill，将点击位置尽量置于画布中心，靠近边缘时自动限制滚动。任何放大状态下再次双击恢复 aspectFit；画布与图片比例相同时，两种模式尺寸一致。
- Ctrl + 滚轮围绕鼠标位置连续缩放，最小为 aspectFit。工具栏加减围绕画布中心缩放，点击“适合窗口”复位。放大后浏览模式可左键拖动画面，裁剪模式可拖动裁剪框外的画面，鼠标中键在框内外均可平移；框内左键继续调整裁剪。缩放和平移不改变裁剪参数，切图恢复适合窗口。
- 缩放停止后按需提升预览分辨率，加载期间保留已有画面及裁剪交互。高精度预览最长边至多 8192 像素，解码目标至多 1600 万像素；极长图片仍可能低于原始分辨率，导出读取原始像素。切图或退出保存草稿；编辑撤销、重做及原像素 100% 检查属于待补齐能力。
- 切换图片时，加载期间的旧画面保留自身宽高比、旋转角度及画布几何；新图片就绪后同步切换图像与几何，不将新图尺寸应用到旧图。新图未就绪时暂停其裁剪交互，失败显示重试入口；同图高清加载仍保留实时缩放和旋转。
- “正在加载图片”仅在当前图片持续未就绪超过 300 毫秒后显示，快速加载不闪提示；切图重新计时，就绪或离开大图模式取消提示。加载失败立即显示错误及重试入口，不等待延迟。
- 大图预览区底部提供横向缩略栏，展示当前批次筛选后的图片顺序。缩略图等比铺满、居中裁切，不显示名称，悬停可查看文件名。点击切换，滚轮及两侧按钮浏览；当前图片高亮并自动保持可见。缩略栏高 96 个逻辑像素，右侧工具区保持全高，图片按需加载。切换前保存草稿并停止视频，旧智能建议不得应用到新图片。
- 预览加载期间显示加载反馈；失败时显示原因及“重新加载”，保留当前素材以便重试或选择其他操作。图片未成功显示时禁止裁剪输出，避免在无预览的情况下确认区域。

## 智能裁剪

大图模式支持持久化的智能模式，根据人物分析及近期裁剪经验生成当前子图的区域。交互保护、成功记录、100 条保留上限与模型方案见[本地智能裁剪](12-smart-crop.md)。

## 多子图流程

打开原图 → 调整方向与区域 → 添加多个子图 → 仅裁剪后逐个归类，或为子图指定目标后裁剪并归类。

每个子图独立保存角度、裁剪区域和目标目录。区域可重叠，目标可不同；修改一个子图不改变其他子图。右侧工具区顶部以紧凑标签切换子图，添加和移除入口集中在标签区域，选中态使用圆角背景；移除只影响草稿，不删除原图或已输出文件。

标签下显示当前子图的独立目标，完整路径可悬停查看；标签提示包含该子图目标和角度。底部明确标注“原文件移至”，只说明移动原文件的目标；“裁剪并归类”始终使用各子图各自的目标，不能将底部路径解释为所有子图的统一输出位置。

导出不会自动切换或移走原图。仅裁剪无需目标目录；裁剪并归类要求每个子图有有效目标。关闭或取消编辑只保留草稿。

## 文件操作

| 操作 | 结果 |
| --- | --- |
| 移动原图 / 移动所选 | 将完整原文件移至所选目录，保留原始内容，不应用裁剪框；已生成的子图也按普通图片移动 |
| 仅裁剪 | 将所有裁剪子图保存到原图所在目录，立即加入当前列表和缩略栏，随后可逐个选择目标并移动 |
| 裁剪并归类 | 将所有裁剪子图直接保存到各自指定目录 |
| 更多 → 复制原文件到所选目录 | 保留来源并复制完整文件，便于重复选择不同目录 |

两种裁剪操作都保留原图及草稿，不自动归档、删除或移走原图。裁剪完成后，用户决定原图与各子图的去向。仅裁剪的输出位置固定为原图所在目录，不覆盖各草稿已选择的目标。

导出前校验全部区域；每个输出写入临时文件、校验并提交。部分输出失败时保留原图和有效结果，重试复用同一编号的已校验输出。全部子图成功且原图未变后保存一条学习记录；重复提交相同操作不重复生成记录。

仅裁剪及复制不让原图离开当前批；只有明确移动文件才从当前批移除。目录名不承担分类状态，普通目录均按扫描范围读取。原图被外部删除后，已有子图仍可用，无法再从缺失的原始像素重新输出。

## 输出规则

默认名称为“原文件名_crop_001”等；重名分配新名称，操作编号保证重试不重复导出。当前统一输出 PNG，按裁剪区域像素尺寸保存；JPEG 输出及质量配置属于后续能力。色彩配置和元数据保留策略通过素材测试验证，不宣称任意裁剪或旋转无损。

子图继承原图拍摄时间；没有可读取拍摄日期时，继承原图用于排序的修改时间及其兜底标记。时间以 UTC 毫秒精度写入 PNG 文本元数据 `ImageClassifier.CaptureTime`，来源写入 `ImageClassifier.TimeSource`，在内容哈希及提交校验前完成写入。再次裁剪子图、移动文件、刷新或在新数据库中重新导入，均可恢复这一时间。文件修改时间仍反映实际写入，不用于伪造拍摄日期。此机制保证归图内排序，不承诺其他软件将自定义 PNG 字段显示为 EXIF 拍摄日期；历史输出不会被自动改写。

统一在 EXIF 纠正后的原图坐标系建立变换，记录原图版本、角度、旋转后画布与裁剪矩形。预览和导出共用变换定义，导出读取原始像素并合并重采样，避免反复编辑已压缩子图。输出方向标记与实际像素一致。

原图外部变化后，旧草稿必须重新核对；移动后的原图更新定位，不破坏子图来源关联。文件落盘、撤销与恢复见[文件安全](06-file-safety.md)。
