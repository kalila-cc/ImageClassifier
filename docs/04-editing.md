# 图片编辑与子图归类

## 编辑交互

双击图片进入编辑工作区；视频进入播放器，Live Photo 提供静态编辑和动态播放入口。编辑保留当前目录与批次上下文，参数保存为草稿，不覆盖原图。

- 当前裁剪比例提供自由、1:1、4:3、3:4 和 16:9；原图比例、自定义比例及保存预设尚未提供。
- 裁剪框内部可拖动移动，四角及四条边均可拖动缩放。四条边中央显示短线手柄，整条边提供命中区域，角点优先响应。自由比例时边拖动仅改变对应方向；固定比例时固定对边，并围绕另一方向的中心对称调整。比例约束形状，默认不放大小裁剪区域或强制缩放成固定尺寸。
- 平移碰到图片边界时，仅限制越界方向，仍可沿边移动，旋转图片沿其实际边界约束。框内移动、边和角缩放均不累积被拒绝的鼠标位移，反向拖动立即响应，无需先把鼠标移回边界。
- 旋转支持任意角度输入与拖动微调，默认步长 0.1 度，提供网格参考线及左右 90 度快捷旋转。
- 拖动旋转滑块时持续更新画面，不等待鼠标松开；输入有效角度立即预览。预览复用已解码图片，裁剪框与旋转画布同步更新，草稿写入独立延后合并，松开滑块时保存。
- 旋转后显示有效图像区域，裁剪框默认限制在实际图像四边形内。旋转时收紧越界区域，四角、四边缩放及框内平移均受边界约束；固定比例保持不变。预览与导出使用相同变换定义，导出另核对像素取整后的四角。原图自身的透明像素不视为几何越界。保留整幅旋转图像时需显式选择透明或背景填充，此模式属于独立功能。
- 默认以 aspectFit 完整展示图片；在图片上双击按当前旋转画布的宽高比放大至 aspectFill，将点击位置尽量置于画布中心，靠近边缘时自动限制滚动。任何放大状态下再次双击恢复 aspectFit；画布与图片比例相同时，两种模式尺寸一致。
- Ctrl + 滚轮围绕鼠标位置连续缩放，最小为 aspectFit。顶部不再展示倍率及缩放按钮，双击已放大的图片恢复适合窗口。放大后浏览模式可左键拖动画面，裁剪模式可拖动裁剪框外的画面，鼠标中键在框内外均可平移；框内左键继续调整裁剪。缩放和平移不改变裁剪参数，切图恢复适合窗口。
- 缩放停止后按需提升预览分辨率，加载期间保留已有画面及裁剪交互。高精度预览最长边至多 8192 像素，解码目标至多 1600 万像素；极长图片仍可能低于原始分辨率，导出读取原始像素。切图或退出保存草稿；编辑撤销、重做及原像素 100% 检查属于待补齐能力。
- 切换图片时，加载期间的旧画面保留自身宽高比、旋转角度及画布几何；新图片就绪后同步切换图像与几何，不将新图尺寸应用到旧图。新图未就绪时暂停其裁剪交互，失败显示重试入口；同图高清加载仍保留实时缩放和旋转。
- “正在加载图片”仅在当前图片持续未就绪超过 300 毫秒后显示，快速加载不闪提示；切图重新计时，就绪或离开大图模式取消提示。加载失败立即显示错误及重试入口，不等待延迟。
- 大图预览区底部提供横向缩略栏，展示当前批次筛选后的图片顺序。缩略图外框为 72×72 的正方形，等比铺满、居中裁切，不显示名称，悬停可查看文件名。点击切换，滚轮及两侧按钮浏览；当前图片高亮并轻微放大至 78×78，缩略栏以 200 毫秒平移动画定位并保持其可见。缩略栏高 96 个逻辑像素，右侧工具区保持全高，图片按需加载。切换前保存草稿并停止视频，旧智能建议不得应用到新图片。
- 预览加载期间显示加载反馈；失败时显示原因及“重新加载”，保留当前素材以便重试或选择其他操作。图片未成功显示时禁止裁剪输出，避免在无预览的情况下确认区域。

## 智能裁剪

大图模式支持持久化的智能模式，根据人物分析及近期裁剪经验生成当前子图的区域。交互保护、成功记录、100 条保留上限与模型方案见[本地智能裁剪](12-smart-crop.md)。

## 多子图流程

打开原图 → 调整方向与区域 → 添加多个子图 → 将结果保存在原目录 → 按需关闭裁剪，再逐个移动或复制归类。

每个子图独立保存角度和裁剪区域。区域可重叠；修改一个子图不改变其他子图。右侧工具区顶部以紧凑标签切换子图，添加和移除入口集中在标签区域，选中态使用圆角背景；移除只影响草稿，不删除原图或已输出文件。

子图标签只管理裁剪区域与角度，不设置归类目录。所有裁剪结果统一留在原图所在目录，需要归类时再关闭裁剪模式，通过移动或复制处理。

## 文件操作

大图模式的操作栏随裁剪模式及子图数量显示两项操作：

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 非裁剪模式 | 移动 | 将当前完整文件移至左侧选定目录，不应用草稿裁剪或旋转 |
| 非裁剪模式 | 复制 | 将当前完整文件复制到选定目录，保留来源 |
| 单子图／多子图 | 仅裁剪 | 将所有子图保存到原目录，立即加入列表和缩略栏；保留原图及草稿，不自动切图 |
| 单子图 | 裁剪并覆盖原图 | 以当前裁剪结果替换原图，继续选中结果；JPG、PNG保持位置、文件名和格式，HEIC、WebP、BMP 等其他格式图片转为同目录静态 PNG |
| 多子图 | 裁剪并删除原图 | 全部子图以独立 PNG 保存到原目录并校验成功后，将原文件移入 Windows 回收站；优先选中第一个可见子图 |

覆盖和删除都支持 Live 图，结果为普通静态图片；配套动态视频一并回收。覆盖原图前先写入、解码及校验临时结果，通过 Windows 文件替换机制保留旧原件备份，校验新文件后回收备份；回收失败不改用永久删除。格式转换遇到已有同名 PNG 时分配新名称，不覆盖其他文件。

批量模式直接提供“移动”和“复制”按钮，不再提供“更多”菜单。两种模式的底部垃圾桶均为独立删除入口：批量处理全部已选项，大图只处理当前一项，确认后回收，不生成子图。

仅裁剪无需归类目标目录。左侧单击选目录只影响后续移动或复制，不改变裁剪输出位置。关闭裁剪保留草稿；重新开启恢复编辑参数。

导出前校验全部区域；每个输出写入临时文件、校验并提交。部分输出失败时保留原图和有效结果，重试复用已校验输出。成功裁剪保存学习记录；重复提交同一操作不重复生成记录。学习记录写入失败单独提示，不撤回成功输出。

覆盖后的图片使用新素材编号并清除当前旧裁剪状态；再次裁剪以新的像素为基础。裁剪并删除原图后，多个子图均留在缩略栏。文件操作失败如实反馈实际结果，未完成记录可手动核对。

## 输出规则

新写入的子图使用独立素材编号，即使复用了已删除图片的文件名，也不继承旧图片的裁剪草稿；旧草稿保留在原编号下。重复提交同一导出时，已校验的现有子图继续沿用自己的编号和草稿。

默认名称为“原文件名_crop_001”等；重名分配新名称，操作编号保证重试不重复导出。先前成功导出的子图已从记录位置删除或移走时，再次提交相同裁剪会新建一条输出记录；后续重试复用最新的完整输出，旧记录保持不变。输出仍存在但内容已修改，或记录确实未完成时，显示对应原因并保留现有文件，不直接覆盖。独立子图输出 PNG；原位覆盖保持受支持的原格式，JPEG 等有损编码质量为 95。均按裁剪区域像素尺寸保存，输出质量的用户配置属于后续能力。色彩配置和元数据保留策略通过素材测试验证，不宣称任意裁剪或旋转无损。

子图继承原图拍摄时间；没有可读取拍摄日期时，继承原图用于排序的修改时间及其兜底标记。时间以 UTC 毫秒精度写入图片文本元数据 `ImageClassifier.CaptureTime`，来源写入 `ImageClassifier.TimeSource`，在内容哈希及提交校验前完成写入。再次裁剪子图、移动文件、刷新或在新数据库中重新导入，均可恢复这一时间。文件修改时间仍反映实际写入，不用于伪造拍摄日期。此机制保证归图内排序，不承诺其他软件将自定义时间字段显示为 EXIF 拍摄日期；历史输出不会被自动改写。

统一在 EXIF 纠正后的原图坐标系建立变换，记录原图版本、角度、旋转后画布与裁剪矩形。预览和导出共用变换定义，导出读取原始像素并合并重采样，避免反复编辑已压缩子图。输出方向标记与实际像素一致。

原图外部变化后，旧草稿必须重新核对；移动后的原图更新定位，不破坏子图来源关联。文件落盘、撤销与恢复见[文件安全](06-file-safety.md)。
