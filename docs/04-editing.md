# 图片编辑与原图归档

## 编辑交互

双击图片进入编辑工作区；视频进入播放器，Live Photo 提供静态编辑和动态播放入口。编辑保留当前目录与批次上下文，参数保存为草稿，不覆盖原图。

- 裁剪比例支持自由、原图、1:1、4:3、3:2、16:9、自定义及保存预设；可切换横竖比例。
- 裁剪框可移动、缩放，显示输出像素尺寸。比例约束形状，默认不放大小裁剪区域或强制缩放成固定尺寸。
- 旋转支持任意角度输入与拖动微调，默认步长 0.1 度，提供网格参考线及左右 90 度快捷旋转。
- 拖动旋转滑块时持续更新画面，不等待鼠标松开；输入有效角度立即预览。预览复用已解码图片，裁剪框与旋转画布同步更新，草稿写入独立延后合并，松开滑块时保存。
- 旋转后显示有效图像区域，裁剪框默认限制在实际图像四边形内。旋转时收紧越界区域，四角缩放及框内平移均受边界约束；固定比例保持不变。预览与导出使用相同变换定义，导出另核对像素取整后的四角。原图自身的透明像素不视为几何越界。保留整幅旋转图像时需显式选择透明或背景填充，此模式属于独立功能。
- 支持适应窗口、100% 检查、局部放大、编辑撤销、重做和重置。切图或退出保存草稿。

## 多子图流程

打开原图 → 调整方向 → 新建裁剪区域 → 加入子图列表 → 指定目标目录 → 继续创建区域 → 导出 → 完成并归档原图。

每个子图独立保存角度、裁剪区域、格式、名称、目标目录和导出进度。区域可重叠，目标可不同；修改一个子图不改变其他子图。子图列表支持预览、修改、放弃草稿、重试失败输出和打开位置。

导出一个子图不会自动切换原图。无目标的子图可保存草稿但不能算导出成功。关闭或取消编辑不自动移动原图。

## 完成与归档

“完成裁剪并归档原图”要求至少存在一个成功导出的子图，且所有保留草稿均已成功导出，其他草稿已明确放弃。

默认归档位置为每个来源根目录下的“已处理”，保留原相对目录结构，可更换位置。它是实际目录，不是分类状态；程序不自动清空或按天删除，用户自行彻底删除原图。

导出失败时原图留在工作目录。导出全部成功但归档失败时保留输出，只重试归档，不重复生成子图。Live Photo 的所有关联成员一起归档。归档目标不能覆盖子图，也不能与正在执行的原图归类冲突。

自动扫描排除归档位置，用户可显式打开。来源本身是归档目录时，选择其他归档位置或保留原图，避免生成连续嵌套的“已处理”目录。原图后来被用户删除时，子图仍保留；来源关联显示缺失，不能再宣称可从原始像素重做。

## 输出规则

默认名称为“原文件名_crop_001”等；重名分配新名称，操作编号保证重试不重复导出。JPEG 照片默认输出 JPEG，透明内容输出 PNG；质量可配置，默认不降低裁剪区域像素尺寸。色彩配置和元数据保留策略通过素材测试验证，不宣称任意裁剪或旋转无损。

统一在 EXIF 纠正后的原图坐标系建立变换，记录原图版本、角度、旋转后画布与裁剪矩形。预览和导出共用变换定义，导出读取原始像素并合并重采样，避免反复编辑已压缩子图。输出方向标记与实际像素一致。

原图外部变化后，旧草稿必须重新核对；移动归档后的原图更新定位，不破坏子图来源关联。文件落盘、撤销与恢复见[文件安全](06-file-safety.md)。
