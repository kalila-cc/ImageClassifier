# ImageClassifier 文档导航

ImageClassifier 是面向 Windows 的本地图片与视频归类工具，支持多目录分批浏览、边界相似性检查、目录树归类，以及图片裁剪和原图归档。

本目录是项目需求、设计、验收与开发进度的维护入口。先阅读产品需求，开发时按模块查阅对应设计，任务状态只在开发进度清单中维护。
