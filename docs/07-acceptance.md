# 验收标准

## 功能用例

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A1 | 父子来源重叠 | 同一文件不重复，独立副本可区分 |
| A2 | N=100 且边界相似 | 连续延伸，到可信差异处切批 |
| A3 | 连续相似达到上限 | 提供选择，不无限扩张；大批分页且解码量受限 |
| A4 | 移入有子目录的父目录 | 文件落在父目录本身，本次浏览不循环入队 |
| A5 | 打开目标目录再建子目录 | 可继续归类，不需要设置分类状态 |
| A6 | 本批移走部分素材 | 不即时补项，选择与滚动锚点稳定 |
| A7 | 一图三个不同目标子图 | 全部正确导出，完成条件满足后才归档原图 |
| A8 | EXIF 方向叠加任意角度 | 预览与输出区域一致，不重复旋转 |
| A9 | 输出重名与重复重试 | 不覆盖，不重复生成成功结果 |
| A10 | 文件操作中强制结束进程 | 重启核对恢复，原图去向可追溯，不误报成功 |
| A11 | 目录改名或移动 | 实际文件、索引和草稿目标一致 |
| A12 | 跨盘不足空间或中断 | 目标完整前保留来源，有恢复入口 |
| A13 | 编辑草稿退出恢复 | 角度、区域、目标保留，不自动导出 |
| A14 | 外部修改原图 | 缓存失效，旧草稿须核对 |
| A15 | 追加来源或新文件 | 当前批不重排，后续不漏项、不重项 |
| A16 | 坏图、操作失败、同目录目标 | 未处理文件保留在列表中，不误记为成功，不隐藏目录文件 |
| A17 | 撤销前外部修改目标 | 显示冲突，不覆盖用户后续操作 |
| A18 | Live 位于批次边界 | 整体计一项、移动全部成员，MOV 不重复入队 |
| A19 | Live 缺失、歧义、重名或部分失败 | 不配错、不误报整项成功，可恢复 |
| A20 | 视频播放与归类 | 验证过的编码可播放，移动前后内容校验一致 |
| A21 | 子图成功但原图归档失败 | 只重试归档，保留已有输出 |
| A22 | 归档位置在来源内 | 扫描不回流，显式打开可浏览 |
| A23 | 用户删除归档原图 | 子图仍可用，来源缺失如实显示 |

## 兼容性与样本

样本集覆盖 JPEG、透明 PNG、带方向信息的照片、HEIC、iPhone Live 导出对、MP4/MOV 真实编码，以及坏文件、长图和大尺寸图片。包含同名无关照片与视频、缺失成员、跨来源配对、无 EXIF、自然文件名和跨日期相似画面。

边界算法记录误切、误纳入、上限触发和人工调整次数，使用人工标注的连续素材校准。对固定回归样本要求已标注边界不回退；额外记录耗时。远距离相关素材不纳入局部边界召回承诺。

## 性能目标

测试基线：Ryzen 5 7500F（6 核 12 线程）、32 GB 内存、RTX 4060 Ti、SN850X 1 TB NVMe SSD、Windows 11 专业版 64 位。记录实际素材盘、软件构建及测试数据规模，显存和磁盘剩余空间由测试环境采集。

| 指标 | 目标与测量方式 |
| --- | --- |
| 素材规模 | 1000、5000、10000 个媒体项，包含 Live 和视频 |
| 缓存打开 | 首屏可操作目标 2 秒内；初次扫描另计 |
| 操作响应 | 选择与菜单等 P95 小于 100 ms；磁盘操作完成时间另计 |
| 网格滚动 | 缓存命中目标接近 60 fps，同时报告 P95 帧时间及长卡顿 |
| 内存 | 常规工作集目标不高于 1.5 GB，大图与视频峰值单列 |
| 边界计算 | 分别测不同、短延伸、上限和人工继续，不等待全库特征 |
| 后台并发 | 扫描、解码、播放和移动时交互仍响应，可取消过期任务 |

这些是验收目标，不能作为未测量的性能结果。CPU 图像、GPU 纹理和任务队列分别观察；图像数量增长不能导致全尺寸图片线性常驻。播放器默认只启用一个。

## 测试与交付

纯逻辑测试覆盖游标、边界扩展、状态转换、坐标变换和重试去重；真实临时文件集成测试覆盖移动、重名、Live 部分失败及中断；交互验收覆盖选择、拖拽、编辑和目录重开。

发布前，A1—A23 均需有结果证据，全部性能目标有实测报告；未达项必须明确处置，不能仅勾选完成。安装包在无开发工具环境验证启动、图片解码、视频播放、升级及业务数据保留，并附依赖许可和使用说明。

实际结果与证据链接统一维护在[开发进度](08-development.md)。
