# 操作流程

## 目录数量变化

移动、复制、裁剪、删除、撤销及继续未完成操作结束后，目录总数右侧显示本次净增减：增加为绿色 `(+N)`，减少为红色 `(-N)`。提示保留 6 秒，下一次文件操作完成后替换为新结果；切换目录树根目录时清除。

变化与目录总数使用相同口径，包含子目录中的图片和视频文件。A 移动两张图片到同级 B 时，A 显示 `(-2)`、B 显示 `(+2)`，共同父目录总量不变，不显示提示。仅裁剪出一张新子图显示 `(+1)`；多子图裁剪并删除原图按净增加量展示；单图覆盖通常不改变数量。Apple Live 配对按现有总数口径计为图片和视频两个文件。

操作前后在后台读取实际目录数量，部分失败或中途停止也只展示实际净变化；数量未知时不猜测。刷新、首次加载和目录改名不产生增减提示。提示不改变收起状态，也不持久化。

## 工作区

主窗口提供“批量模式”和“大图模式”，共用当前来源、批次及目标目录。目标目录树常驻左侧，来源管理从顶部打开；图片信息、批次边界及低频设置按需展开，不占用常驻详情栏。底部固定显示当前操作范围、目标和主要动作。

批量模式右下方直接提供“移动”和“复制”：移动后原位置不再保留，复制则保留来源文件。两项均作用于全部已选文件，包含筛选隐藏的选择；未选择文件、未指定目标目录或任务执行中时不可用。已选数量集中显示在底部左侧。

右上角“重启应用”保存当前编辑草稿和浏览记录后重新打开归图。文件任务执行中或弹窗打开时禁用；保存或启动准备失败不关闭当前窗口。重启恢复持久化的批次、模式与草稿，不执行文件归类操作。

- 批量模式：正方形图片网格无间距铺满浏览区，图片等比铺满并居中裁切，不显示文件名标签（悬停可查看），可调整缩略图大小，筛选、搜索、多选后统一归类；双击按实际命中的卡片及图片唯一编号打开对应大图。窗口缩放、滚动、筛选和刷新后仍保持对应；列表空白区域不会打开图片，拖选完成不会触发大图跳转。
- 大图模式：以单张大画布为主，支持上一张 / 下一张、放大查看及拖动；非裁剪且适合窗口时，在图片上按住鼠标左键向左拖动切下一张、向右拖动切上一张，图片水平位移实时跟随鼠标，超过阈值显示方向提示，松手切换一张；旧图保持松手位置直到新图就绪，新图按切换方向从对应侧滑入，旧图同步滑出。大图模式下预载前后各一张静态预览（含 Live 封面），切换复用解码缓存，离开大图模式释放预载引用。短拖和首尾越界松手后平滑回到原位；纵向拖动不切换；放大时拖动用于平移，裁剪状态与视频／Live 播放不触发拖拽切图；胶片条随当前图片平滑定位，选中缩略图轻微放大，取消选中平滑恢复；胶片条可收起。归类动作仅作用于当前图片，不继承批量模式的选择范围。
- 大图模式继承上次的裁剪模式选择，首次使用默认开启。通过“裁剪 / 旋转”或工具区关闭按钮切换时立即保存，切图、跨目录、重新进入大图及重启均保持；关闭不清除裁剪草稿。关闭时提供移动和复制；开启时提供仅裁剪，以及单子图的裁剪并覆盖原图或多子图的裁剪并删除原图。裁剪结果统一保存在原目录。视频只提供播放预览和原文件归类，不改变保存的裁剪模式偏好。
- 切换模式保留当前图片、筛选、目标目录和批量选择。从大图返回批量模式时，自动滚动到刚才浏览的图片或视频，对应缩略图用 350 毫秒放大至 110%，再用 550 毫秒复原，便于辨认位置；不额外选中该项。来源、批次、范围计数集中显示于紧凑工具栏，不重复展示说明或文件属性。

支持单击切换选择、按图片顺序拖选、空白框选和当前筛选结果全选。移走素材后不即时补入下一项；大图模式保持原浏览顺序，优先切至原位置之后仍在列表中的图片，末项移走时回到前一张。卡片用文字或图标标明视频、Live、加载及失败状态，不能只依赖颜色。

批量模式调整缩略图尺寸后，按选择顺序定位到当前列表中最后选中的图片。鼠标拖动尺寸滑块时只改变布局，松开后等待新布局完成再滚动；键盘调整尺寸也定位。在图片区域按住 Ctrl 向上滚动放大缩略图，向下滚动缩小，与滑块共用 170—730 的尺寸档位范围及 35 的步长；按浏览区宽度比例计算实际显示尺寸，同一档位在大窗口中同步放大，最多可放大为两列，设置自动保存，调整后同样定位选中项。普通滚轮继续滚动列表；弹窗、设置页、文件任务及拖选期间不响应批量缩放。被筛选隐藏的选择保持不变，优先定位仍在当前列表中的最近选中项；没有可见选择时不额外滚动，不改变筛选或当前图片。

按住图片拖动时，按当前筛选列表的排列顺序选择起点至终点的连续范围，跨行包含中间行的全部图片。例如五列网格从 02 拖到 14，选中 02—14 共 13 张。支持反向拖动、拖回缩小范围、边缘自动滚动；原有选择保留，松开后结束，拖动中按 Esc 恢复拖动前的选择。从末行剩余空白区域起拖则使用矩形框选。

批量模式在“全选”旁提供“取消选择”，一次取消当前批的全部选择，包括筛选后不可见的已选项。底部明确显示“N 项已隐藏 · 取消选择”，说明隐藏选择仍参与移动，点击仅取消被筛选隐藏的选择。无选择或文件操作执行中时清空按钮禁用；取消选择不改变筛选、图片文件和编辑草稿。

快捷键遵循当前界面与输入焦点：批量工作区 Ctrl+A 选择当前筛选结果，Esc 清空选择；拖选进行中 Esc 只撤回本次手势。大图工作区左右方向键切图，角度输入或滑块拥有焦点时用于调整数值。文本输入期间保留文字编辑快捷键，弹窗及设置页不触发后台切图或批量选择。F5 刷新当前浏览范围，文件操作、弹窗或设置页打开时禁用；设置页 Esc 返回工作区。编辑撤销重做属于待补齐能力，不声明 Ctrl+Z 已支持。

批量与大图模式采用一致的空状态，区分未添加来源、没有匹配结果、来源暂无待整理文件及正在准备图片，并分别提供添加来源、清除筛选、刷新入口。空大图模式不展示无可操作对象的裁剪面板。输入框使用统一的边框、文字对比度、鼠标悬停和键盘焦点样式。

## 目录浏览与归类

底部操作完成后，在右下角操作栏上方显示不抢焦点的 Toast：移动、复制、仅裁剪、裁剪并覆盖原图、裁剪并删除原图和直接删除均以实际结果反馈；手动加入文件或加载下一批也提供结果提示。成功使用绿色勾号，失败使用红色叉号，部分完成或停止使用琥珀色感叹号，图标播放一次描绘动画并显示完成数量与原因。成功提示约 3.6 秒后收起，失败与部分完成提示约 7 秒；悬停暂停计时，可主动关闭，连续结果依次展示。较长错误可通过“查看详情”查看全文；文件操作记录仍负责持久化核对与恢复。

顶部“来源目录”打开来源管理弹窗。浏览范围以目录名称、完整路径和“已添加／待添加”标记组成清单，可通过“添加目录…”选择，也可展开“粘贴路径”逐行加入。支持带引号的资源管理器路径和本地文件 URL；无效输入在弹窗内提示并保留，重复目录不重复加入。移出清单仅调整浏览范围，不删除磁盘文件或裁剪草稿。

已有来源时，添加、移出目录或更改“包含子目录”后，点击“保存更改”统一生效；没有修改时主按钮为“刷新列表”，首次添加来源时为“开始整理”。底部提示明确标记尚未保存的修改。取消或 Esc 放弃本次清单编辑。已有来源沿用当前递归范围，首次添加才使用设置页中的默认值。追加目录保留当前批，新文件进入待加载队列；移除来源或改变递归范围时重新分批。扫描中锁定表单并提供取消扫描，失败或取消保留原工作区和暂存清单，成功后关闭弹窗。全部移出后显示“已移出全部来源目录”，提示“保存后不再浏览任何来源目录，磁盘文件保留”；仍点击“保存更改”提交，文件和裁剪草稿保留。

路径输入中 Enter 换行，Ctrl+Enter 将路径加入清单；输入尚未加入时禁用主提交，避免遗漏。表单其余位置 Ctrl+Enter 应用清单，普通 Enter／空格遵循聚焦按钮的操作。

左侧常驻“归类目录”标题、刷新图标、“…”管理菜单及目录树，不重复放置更换根目录和资源管理器按钮。仅未选择根目录时显示“选择归类目录”引导。根节点显示目录名称，完整路径通过悬停查看；刷新使用独立图标，更换根目录放在管理菜单，针对单个目录的操作放在该目录右键菜单。

- 多目录首次加入默认递归；双击目录树节点或右键选择“打开此目录”即可切换工作目录，仅读取直属文件；以前移动归类的文件也可重新查看和调整，不按已处理记录隐藏。
- 父子来源重叠时同一文件只入队一次。移除来源不删除文件；目录链接和重解析点默认不递归跟随。
- 排除缓存和临时文件；普通目录不按名称或处理历史排除。
- 单击目录行立即选为归类目标，保留当前工作目录、图片和多选；随后点击底部归类按钮执行移动。大图模式下单击目录只设置移动或复制目标，不改变裁剪输出位置。双击目录行或右键选择“打开此目录”切换工作目录，仅显示直属图片和视频；双击撤回首次单击带来的目标变化，避免仅浏览目录时改写移动或复制目标。切换前保存裁剪草稿，再清空批量选择和筛选。左侧展开箭头只负责展开。
- 任意目录都可接收素材，也可随时重新打开进行调整。侧栏标题旁的刷新图标用于“刷新目录与图片”，重新读取当前浏览范围并更新目录树及数量；空目录显示“此目录暂无直属图片或视频”。有子目录的节点通过左侧箭头展开或收起，单击名称用于选择归类位置，双击打开直属文件；目标目录使用背景高亮，当前浏览目录标记“工作”；默认全部展开，刷新数量保留各层收起状态，更换目标根目录后重新展开。收起不会改变当前归类目标或目录总数。每个目录右侧显示包含所有子目录的媒体文件总数；悬停分别显示含子目录合计、当前目录直属数量及图片与视频明细。无法完整读取或超出目录树遍历上限时显示省略号，不把部分统计当作总数。启动、归类、撤销、恢复及导出后更新，可通过标题旁的刷新图标同步外部文件变动。数量按当前支持的媒体扩展名统计，不解码图片，不计普通文档、链接和应用临时文件；Live Photos 在元数据配对完成前按照片和视频两个文件计数。
- 右键目标根目录或任意子目录可新建子目录、重命名、在资源管理器中打开该目录。右键不会改变当前归类或裁剪输出目标。新建成功后展开父目录，重命名后保留收起状态，根目录改名同步更新目标根路径，并同步当前目标、来源、草稿及移动记录中的后代路径。非法名称与同名冲突不执行覆盖。
- 新建、改名、移动目录作用于真实目录及全部内容。禁止移入自身或后代，重名目录不自动合并；删除操作仅提供删除空目录。
- 目标就是原目录时提示“已在此目录”，不复制、不隐藏，图片继续留在当前列表。
- 打开“初中”、新建“初二”后可以直接继续归类，不存在需要设置的分类完成状态。

## 批次与排序

默认批次目标 N=100，自动延伸上限为 2N，均可配置。计数单位为媒体资产：普通图片、视频和完整 Live Photo 各计一项。

先建立轻量文件清单，再准备当前批与边界小图，不等待全库视觉分析。多个来源合并后统一按拍摄时间从新到旧排序。照片读取拍摄日期，视频使用媒体创建日期；文件未提供可读取的时间时，以文件修改时间兜底，不把该时间标记为真实拍摄时间。时间相同时按完整路径的自然顺序稳定排列。

裁剪子图继承原图的排序时间及时间来源，刷新和重新打开目录仍按同一规则排列。刷新保留当前批次成员、选择及当前图片，更新成员时间并重排；新发现的文件进入后续队列，手动加入当前批时统一排序。启动先呈现已保存的批次，并自动在后台按来源范围重新扫描，更新文件版本、时间和 Live 配对，移除确认已不存在的文件；来源不可用或扫描取消时保留浏览记录。删除或裁剪后回收的原图重新出现在原路径时，启动及刷新会解除对应的已处理标记并加入当前批，自动加入最多到 2N，超出部分进入待加载队列；已经移动到子目录的文件仍保持已处理状态。新发现的其他文件进入待加载队列。重新打开目录会对全部候选重新排序和分批。

1. 从未处理候选中取 N 项，不足 N 时取剩余项。
2. 比较本批末项与下一项；先纠正方向，再提取小图感知哈希、颜色和结构特征，时间作为辅助。
3. 判断不相似则切批；相似则纳入下一项，继续检查新边界。
4. 判断不确定则展示两侧预览，由用户保持边界或继续纳入；允许手动调整边界。
5. 达到自动延伸上限仍相似时停止自动扩展，提供继续或分批选择。大逻辑批次分页显示，不增加全尺寸解码量。
6. 对连续相似长链复核代表图与时间跨度，内容漂移时转为不确定。解码失败、缺少时间和视频取帧失败不能直接判为不相似。

例如 N=100，连续延伸到第 112 项，112 与 113 不相似，则本批 112 项，下一批从 113 开始。检查只发生在局部边界，可有限预取，不进行全库两两比较。特征实现参考 [OpenCV 图像哈希](https://docs.opencv.org/4.x/d4/d93/group__img__hash.html)。

## 换批与恢复

当前批中的素材通过明确移动、直接删除或裁剪并删除原图移出；仅裁剪与复制保留原图，仅裁剪将新子图加入当前批，覆盖以新素材替换当前项。进行中的操作和未决定的草稿必须先处理；失败项留在列表中供核对、调整或重试，不能记作成功。当前批清空后默认自动换批，可设置停留。

当前范围包含目标子目录时，刚移动或导出的素材不在本次浏览中循环入队。未处理图片不提供隐藏或跳过功能。重新打开目录或选择“重新开始”，按实际内容重新枚举；选择“恢复浏览”则恢复原批次、游标和草稿。

刷新读取当前范围并更新目录数量、现有素材版本与缩略图，保留筛选、仍存在的选择、当前图片及浏览顺序；当前图片缺失时按相邻顺序继续。仅系统明确确认路径不存在时移除列表项，无法读取不等于已删除。刷新不把缺失项记为已处理，外部恢复后仍可入队；当前批因文件缺失变空时不自动消耗下一批。

新来源和外部新增文件经扫描进入后续队列，不自动补满或重排当前批，可通过“再加入 N 项”加入，每次最多 10 项，按钮显示实际可加入数。当前范围内已明确移动的文件不循环入队，重新打开目录时重新按实际内容读取。外部修改使缩略图和旧版本草稿失效；旧草稿不得因刷新而被保存成新版本，需重新核对区域后处理。

文件冲突、目录变更协调及恢复机制见[文件安全](06-file-safety.md)。
