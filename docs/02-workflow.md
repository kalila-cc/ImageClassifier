# 操作流程

## 工作区

主窗口提供“批量模式”和“大图模式”，共用当前来源、批次及目标目录。目标目录树常驻左侧，来源管理从顶部打开；图片信息、批次边界及低频设置按需展开，不占用常驻详情栏。底部固定显示当前操作范围、目标和主要动作。

- 批量模式：图片网格占据主要空间，可调整缩略图大小，筛选、搜索、多选后统一归类；双击图片进入大图模式。
- 大图模式：以单张大画布为主，支持上一张 / 下一张、放大查看及拖动；胶片条可收起。归类动作仅作用于当前图片，不继承批量模式的选择范围。
- 图片进入大图模式即展开裁剪和旋转工具，保留目标目录树及子图列表；主要动作为保存子图并归档原图。可手动收起工具仅查看图片；再次进入大图模式或切换到另一张图片时默认展开。视频只提供播放预览和原文件归类。
- 切换模式保留当前图片、筛选、目标目录和批量选择。来源、批次、范围计数集中显示于紧凑工具栏，不重复展示说明或文件属性。

支持单选、Ctrl 多选、Shift 连选、框选和当前批全选。跨页选择显示总数；移走素材后保持滚动锚点，不即时补入下一项。卡片用文字或图标标明视频、Live、执行中和加载失败，不能只依赖颜色。

按住图片拖动时，按当前筛选列表的排列顺序选择起点至终点的连续范围，跨行包含中间行的全部图片。例如五列网格从 02 拖到 14，选中 02—14 共 13 张。支持反向拖动、拖回缩小范围、边缘自动滚动；原有选择保留，松开后结束，拖动中按 Esc 恢复拖动前的选择。从卡片间空白处起拖则使用矩形框选。

批量模式在“全选”旁提供“清空选择”，一次取消当前批的全部选择，包括筛选后不可见的已选项。无选择或文件操作执行中时按钮禁用；清空选择不改变筛选、图片文件和编辑草稿。

快捷键：Ctrl+A 选择当前批，Enter 预览，Esc 退出当前编辑或选择，方向键切图。Ctrl+Z 根据焦点撤销编辑或文件操作，提示具体动作；文本输入时禁用归类快捷键。

## 目录浏览与归类

- 多目录首次加入默认递归；双击目录树节点或右键选择“打开此目录”即可切换工作目录，仅读取直属文件；以前移动归类的文件也可重新查看和调整，不按已处理记录隐藏。
- 父子来源重叠时同一文件只入队一次。移除来源不删除文件；目录链接和重解析点默认不递归跟随。
- 排除缓存、临时文件与已登记的归档目录；归档目录仍可主动打开。
- 单击目录行立即选为归类目标，保留当前工作目录、图片和多选；随后点击底部归类按钮执行移动。大图模式下单击目录设置当前子图输出目录。双击目录行或右键选择“打开此目录”切换工作目录，仅显示直属图片和视频；切换前保存裁剪草稿，再清空批量选择和筛选。左侧展开箭头只负责展开。
- 任意目录都可接收素材，也可随时重新打开进行调整。侧栏“刷新当前目录”重新读取当前目录直属文件；空目录显示“此目录暂无直属图片或视频”。有子目录的节点通过左侧箭头展开或收起，单击名称用于选择归类位置，双击打开直属文件；目标目录使用背景高亮，当前浏览目录标记“工作”；默认全部展开，刷新数量保留各层收起状态，更换目标根目录后重新展开。收起不会改变当前归类目标或目录总数。每个目录右侧显示包含所有子目录的媒体文件总数；悬停分别显示含子目录合计、当前目录直属数量及图片与视频明细。无法完整读取或超出目录树遍历上限时显示省略号，不把部分统计当作总数。启动、归类、撤销、恢复及导出后更新，可点击目录标题旁的“刷新”同步外部文件变动。数量按当前支持的媒体扩展名统计，不解码图片，不计普通文档、链接和应用临时文件；Live Photos 在元数据配对完成前按照片和视频两个文件计数。
- 右键目标根目录或任意子目录可新建子目录、重命名。右键不会改变当前归类或裁剪输出目标。新建成功后展开父目录，重命名后保留收起状态，根目录改名同步更新目标根路径，并同步当前目标、来源、草稿及移动记录中的后代路径。非法名称与同名冲突不执行覆盖。
- 新建、改名、移动目录作用于真实目录及全部内容。禁止移入自身或后代，重名目录不自动合并；删除操作仅提供删除空目录。
- 目标就是原目录时提示“已在此目录”，不复制、不隐藏，图片继续留在当前列表。
- 打开“初中”、新建“初二”后可以直接继续归类，不存在需要设置的分类完成状态。

## 批次与排序

默认批次目标 N=100，自动延伸上限为 2N，均可配置。计数单位为媒体资产：普通图片、视频和完整 Live Photo 各计一项。

先建立轻量文件清单、稳定排序和 Live 配对，再准备当前批与边界小图，不等待全库视觉分析。默认按来源顺序、相对目录、自然文件名排序；可改按拍摄时间，缺失时间使用路径与自然文件名回退键。文件修改时间不等于拍摄时间。

1. 从未处理候选中取 N 项，不足 N 时取剩余项。
2. 比较本批末项与下一项；先纠正方向，再提取小图感知哈希、颜色和结构特征，时间作为辅助。
3. 判断不相似则切批；相似则纳入下一项，继续检查新边界。
4. 判断不确定则展示两侧预览，由用户保持边界或继续纳入；允许手动调整边界。
5. 达到自动延伸上限仍相似时停止自动扩展，提供继续或分批选择。大逻辑批次分页显示，不增加全尺寸解码量。
6. 对连续相似长链复核代表图与时间跨度，内容漂移时转为不确定。解码失败、缺少时间和视频取帧失败不能直接判为不相似。

例如 N=100，连续延伸到第 112 项，112 与 113 不相似，则本批 112 项，下一批从 113 开始。检查只发生在局部边界，可有限预取，不进行全库两两比较。特征实现参考 [OpenCV 图像哈希](https://docs.opencv.org/4.x/d4/d93/group__img__hash.html)。

## 换批与恢复

当前批中的素材须移动或完成编辑归档，才能进入下一批。进行中的操作和未决定的草稿必须先处理；失败项留在列表中供核对、调整或重试，不能记作成功。当前批清空后默认自动换批，可设置停留。

当前范围包含目标子目录时，刚移动或导出的素材不在本次浏览中循环入队。未处理图片不提供隐藏或跳过功能。重新打开目录或选择“重新开始”，按实际内容重新枚举；选择“恢复浏览”则恢复原批次、游标和草稿。

新来源和外部新增文件在下一批或刷新时纳入，不重排当前选择。游标使用稳定资产身份与批次快照，不因删除或移动造成列表下标变化而漏项。外部修改使特征、缩略图和旧草稿失效，重新核对后再处理。

文件冲突、目录变更协调及恢复机制见[文件安全](06-file-safety.md)。
