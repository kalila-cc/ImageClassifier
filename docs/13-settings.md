# 设置与全局偏好

右上角“设置”打开独立设置页，分为“浏览与批次”“裁剪与智能”“本地数据”“主题配色”。点击“返回整理”或按 Esc 返回工作区。设置页不作为下次启动页面。

## 配置项

| 配置 | 默认值 | 生效规则 |
| --- | --- | --- |
| 浏览模式 | 批量模式 | 与顶部模式按钮双向同步，重启恢复上次选择 |
| 裁剪模式（工作区按钮） | 开启 | “裁剪 / 旋转”与工具区关闭按钮立即保存选择；切图、跨目录、返回大图和重启保持；视频不改变此偏好，关闭保留草稿 |
| 批量缩略图大小 | 240 个逻辑像素的目标列宽 | 范围 170—730，步长 35；与工作区滑块同步，实际卡片按窗口宽度排布 |
| 每批目标数量 | 100 | 范围 10—500，从下一批生效，不重新分割当前批；边界相似性扩展规则不变 |
| 默认勾选“包含子目录” | 开启 | 无来源时作为来源对话框的初始值；已有来源时显示实际递归范围。点击“开始整理”（首次添加）或“保存更改”（已有来源）后，将本次选择用于全部来源，范围改变时重新分批；双击左侧目录始终只浏览其直属图片或视频 |
| 显示底部缩略栏 | 开启 | 控制大图模式的缩略栏；隐藏后释放其预览空间，左右方向键仍可切图 |
| 主题配色 | 薄荷单色 | 6 组单色和 4 组双色渐变预设，支持自定义主色、副色；立即生效并在重启后恢复 |
| 智能裁剪 | 关闭 | 与编辑区“智能模式”同步；大图中的裁剪模式开启时，按现有手动草稿保护规则生成建议 |

智能裁剪分组提供本地模型状态、安装模型、重新检测、学习记录数量和打开记录目录。模型默认不下载，仅用户点击安装后启动后台任务；显示“未安装 / 安装中 / 已安装 / 安装失败”及当前阶段，失败支持重试和打开日志目录。安装任务独立于应用窗口，关闭或重启应用后继续执行。未安装或安装中时，设置及编辑区的智能控件禁用，手动裁剪不受影响；完成后恢复可用，首次安装不自动打开智能开关。最近记录保留上限为 100 次操作，不在设置页更改，成功记录规则见[本地智能裁剪](12-smart-crop.md)。

本地数据分组展示应用数据目录并支持打开，说明移动、复制、仅裁剪、覆盖及裁剪并删除原图的文件去向。此页不提供清空素材或删除学习数据操作。

## 主题配色

单色预设为薄荷、晴蓝、蜜桃、樱粉、奶杏、浅藤；渐变预设为海盐、朝霞、春日、晴空，均采用清爽的亮色。切换单色或渐变保留当前主色、副色，点击预设应用该组合。“恢复默认”回到薄荷单色。

主色和副色可以通过色块打开系统取色器，或输入 `#RRGGBB` 修改。输入完成即保存；无效颜色在输入框下提示，不写入配置。选色对话框取消不改变颜色。亮色保留原色，顶部、主按钮及选中态的文字与配套图标使用柔和深灰（优先 `#4B5358`）；背景较暗时适度加深文字，保证可读性。按钮文字和图标优先使用更柔和的 `#59636A`，统一中等字重及略细的图标笔画；有色背景按需加深文字以保持对比度，按钮背景沿用主题设置；“移动”按钮直接复用照片勾选标识的高饱和主色，搭配白色文字和图标，不加描边；渐变副色采用相同的配色规则，设置页预览同步，悬停和按下时逐级加深。细小控件和边框继续使用主题色。自定义深色或明暗跨度较大的渐变会加深背景，以确保同一组文字在两个端点上都清晰，输入值保持原样。已有用户的配色保持不变，点击预设或“恢复默认”可切换到亮色。

工作区和设置页的顶部栏使用主色，渐变模式下铺满主色到副色的横向渐变；栏内文字和图标随背景明暗使用深灰或白色，当前模式以白底深灰文字区分，悬停与按下使用半透明覆盖层。较大的主按钮和选中背景采用从主色到副色的水平渐变。普通控件、文字、图标、勾选框、滑块和焦点使用主色或同色系深浅色；选中图片使用 5 像素白色方形边框，居中沿图片边界绘制，相邻选中图片的公共边完全重叠；图片及卡片尺寸和位置不变。照片左上角勾选标识采用圆形，使用同色相、提高饱和度的主题主色，并控制亮度以突出白色勾号，统一搭配稍粗的白色勾号，标识尺寸为 25×25，选中时增加 1.5 像素白色描边；勾选标识不应用渐变。小于 64×32 的按钮不启用渐变；目录选中行使用更明显的主题底色，默认深于普通悬停背景，选中后悬停与按下逐级加深；渐变的两端保持相同强调程度。照片、视频及深色预览画布不染色，成功、危险与警告反馈保留语义色，应用 Logo 保留品牌配色。

配色通过共享 `Theme.qml` 实时生效，不重新加载素材或重置选择、裁剪草稿。裁剪比例和旋转 SVG 复用原文件，由图片提供器按颜色生成小尺寸图标，不依赖 GPU 着色效果。

## 工作区保护

- 进入设置前保存当前草稿、停止视频并使未完成的智能建议失效。
- 工作区保持挂载，保留当前图片、筛选、目标目录与多选；设置页不触发文件归类。
- 在设置页屏蔽后台左右切图、批量全选和刷新快捷键；方向键可以正常调整设置控件，Esc 返回原工作区。输入框与按钮提供清晰的键盘焦点状态。
- 返回大图时保持已有编辑内容，不因开关页面重置缩放或裁剪比例。
- 文件任务进行时，浏览模式和批次数量不可修改；其他界面偏好可保存。

## 持久化

更改自动写入当前应用数据目录的 `library.sqlite` 中的 `settings` 表。写入失败显示提示；不另建配置文件。使用隔离数据目录运行测试时，配置也随该目录隔离。

| 配置键 | 值 |
| --- | --- |
| `theme` | JSON 对象：`mode` 为 `single` / `gradient`，`primary` 和 `secondary` 为六位十六进制颜色 |
| `viewMode` | `batch` / `large` |
| `cropMode` | `1` / `0` |
| `thumbnailSize` | 170—730 |
| `batchSize` | 10—500 |
| `defaultRecursive` | `1` / `0` |
| `showFilmstrip` | `1` / `0` |
| `smartCropEnabled` | `1` / `0` |

批次及智能模式复用现有配置。其他偏好使用独立通知信号，避免界面设置触发素材清单刷新。界面保留常用快捷入口，各入口共用同一配置值。
