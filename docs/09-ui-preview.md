# UI 预览

本页只描述独立的静态界面演示。使用真实文件功能请按[功能版运行说明](10-running.md)启动 `Start.cmd`。

## 启动

在项目根目录双击 `Preview.cmd`，或使用 PowerShell 运行 `./Start-Preview.ps1`。预览使用项目内 `.venv`，演示图片保存在 `ui/assets`，日常启动无需联网。

重新建立预览环境时，在项目根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-preview.txt
.\.venv\Scripts\python.exe preview.py
```

## 界面范围

| 区域 | 可体验内容 |
| --- | --- |
| 批量模式 | 大面积图片网格、缩略图大小滑块、媒体筛选、文件名搜索、全选 / 清空、底部批量归类栏 |
| 大图模式 | 单张大画布、上一张 / 下一张、左右方向键切图、放大后拖动、可收起胶片条、当前单张归类 |
| 模式切换 | 顶部直接切换；双击缩略图进入大图；保留批量选择、当前图片、筛选与目标目录 |
| 裁剪与旋转 | 图片进入大图模式即展开工具区，无需再次点击；切换图片时默认展开，视频仅保留播放预览。可切换比例和旋转角度，底部提供保存子图并归档原图 |
| 目标与弹层 | 常驻目标目录树；来源管理、图片信息、新建目录、批次边界按需打开 |

“添加目录”“确认归类”“完成处理”等业务按钮仅展示提示。裁剪框不支持拖拽，不生成实际裁剪结果；子图卡片为布局演示。Live 和视频标记使用静态示例图片，不提供真实配对或播放。

不扫描用户目录，不移动、删除或修改用户媒体，不保存设置。关闭窗口后，演示选择和参数恢复默认值。文件属性、时间、来源路径均为示例信息。

## 视觉与代码组织

浅色工作台搭配墨绿色强调色。批量模式以缩略图网格为主，大图模式使用深色画布；仅目标目录和当前操作常驻。来源列表、文件属性及边界检查使用弹层，裁剪工具和胶片条可收起，优先保留图片展示和处理面积。

| 位置 | 职责 |
| --- | --- |
| `ui/Main.qml` | 工作台、内存演示数据、弹层、视图切换 |
| `ui/BatchView.qml` | 批量网格、缩略图密度、筛选与选择 |
| `ui/Editor.qml` | 大图浏览、缩放、胶片条及默认展开、可手动收起的裁剪工具 |
| `ui/PhotoCard.qml` | 图片选择卡片 |
| `ui/FolderRow.qml` | 目录树行 |
| `ui/UiButton.qml`、`ui/Glyph.qml` | 共享按钮和线性图标 |
| `preview.py` | 加载 QML 的临时预览启动器 |
| `requirements-preview.txt` | 预览运行时版本 |

静态演示由 PySide6 Essentials 加载 `ui/Main.qml`，启动器不承担产品业务逻辑。原生功能版由 C++ 加载 `ui/Application.qml`，两者共享基础视觉组件，功能入口相互独立。

## 验证边界

已在本机原生窗口检查批量模式、大图模式及裁剪面板，并验证模式切换保留选择、缩略图大小调整和单张 / 批量操作范围。预览运行日志无 QML 错误。

本阶段不验证真实图片算法、Live Photos 配对、文件安全、导出质量或大规模性能；对应验收仍由[开发进度](08-development.md)管理。
