# 产品需求

## 产品目标

为几千份本地图片、iPhone Live Photos 和视频提供流畅的人工归类体验。用户把素材移动到真实目录，按需要继续细分；软件不要求用户维护“待细分”或“已完成”标签。

典型流程：加入多个目录 → 分批查看 → 移入目标目录，或裁剪后分别归类 → 按需移动或复制原图与子图 → 处理下一批。打开任意目标目录、新建子目录后，即可继续整理其中的实际文件。

## 核心约束

- 归类直接作用于真实文件系统。未编辑素材移动时保持原文件内容，不重新编码。
- 同一批素材可以分别进入不同目录；视觉相似只影响一起展示，不决定目标目录。
- 仅裁剪保留原图；显式选择覆盖时以单子图替换原图，多子图可选择全部保存后回收原图；直接删除需确认；移动前后核对内容一致，复制保留来源。
- 重名不覆盖，失败不算成功，文件操作可追踪，并在条件允许时撤销和恢复。
- 媒体处理在本地执行；核心流程不依赖云端服务。

## 范围边界

本产品不包含云同步、多人协作、全库语义聚类、自动分类目录、人脸身份识别、OCR、透视矫正或专业修图。

视频不提供剪辑、截帧和画面裁剪。Live Photo 编辑仅从静态部分输出普通图片，不生成重新编辑的 Live Photo。

边界检查保护相邻素材的处理连续性，不能保证找出相隔很远的同一拍摄事件，也不能把风格相似直接等同于同一事件。
