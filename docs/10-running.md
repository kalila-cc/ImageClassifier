# 功能版运行说明

## 启动与数据

完成依赖安装和构建后，在项目根目录双击 `Start.cmd`，启动 C++ 原生功能版。脚本自动配置本项目 Qt 运行环境，不需要手动写代码或启动 Python。`Preview.cmd` 仅用于静态 UI 演示，需安装 `requirements-preview.txt` 中的依赖。

功能版使用真实文件：归类会移动文件，裁剪会生成子图并归档原图。界面不会自动永久删除“已处理”目录中的原图。

浏览范围、批次、草稿及操作日志保存在 `%LOCALAPPDATA%\ImageClassifier\ImageClassifier\library.sqlite`。同一数据目录只允许一个实例。测试可通过环境变量 `IMAGECLASSIFIER_DATA_DIR` 指定隔离数据目录。运行日志位于项目根目录 `app.log`、`app-error.log`。

## 使用流程

1. 点击顶部“来源”，选择目录，或每行输入一个目录后添加；可设置是否递归读取。扫描只建立清单，图片按需解码。
2. 在左侧选择目标根目录。点击任意目录即可作为归类位置，包括含有子目录的父节点；“＋”在当前选中的目录下新建子目录。
3. 批量模式中单击图片可选择或取消。从图片按住左键拖动，按显示顺序连续多选；从网格空白处起拖则按矩形框选。松开后保留，原有选择不受影响，按 Esc 撤回本次拖选。拖到上下边缘会自动滚动。“清空选择”可取消全部选择。选择完成后单击目标目录，再点击底部归类按钮。已移动项移出当前批；处理完当前批后自动准备下一批。
4. 大图模式直接展示裁剪框及旋转工具。拖动边角调整区域、拖动内部移动区域；选择比例或输入角度微调。
5. 需要多个输出时添加子图，每个子图可独立设置区域、角度和目标。先选择子图，再点击左侧目标目录。点击“导出子图并归档原图”执行全部输出。
6. 需要继续调整已归类图片时，双击目录或右键选择“打开此目录”，仅读取直属文件。单击目录仅选择归类目标，保留当前工作目录和多选；工作目录标记“工作”，归类目标以背景高亮。软件不要求设置“已完成 / 待细分”业务状态。

批次默认 100 项，可在“批次”中设置 10—500 项，对下一批生效。边界相似时逐项延伸，自动上限为目标数量的两倍；不确定时提示，可手动再纳入 10 项。判断使用缩小图的差异哈希和颜色距离，尚未经过真实图库校准。

未处理图片保留在当前列表中，不提供隐藏或跳过操作。切图及退出时保存编辑草稿，重启恢复当前批。界面模式与当前光标位置不持久化。

## 输出与文件操作

- 子图按原图像素计算，当前统一输出 PNG。裁剪框限制在旋转后的实际图像四边形内；旋转或恢复旧草稿时自动收紧越界区域，拖动及缩放会停在边界。导出前校验全部子图，拒绝越界参数，不输出旋转产生的空白角。原 PNG 自身的透明内容仍保留。
- 默认裁剪区域为中心 80%，旋转后可能缩小，以当前画面中的裁剪框为准。四角均可拖拽缩放，拖动框内可移动；角点的可点击区域为 28×28 个逻辑像素。
- 只有全部子图输出成功，才将原图移到对应来源下的 `已处理`，保留原有相对目录。直接归类移动不会进入归档目录。
- 重名文件自动添加数字后缀，不覆盖目标。已成功的子图输出通过固定编号校验，原参数重试复用有效输出。
- “操作记录”提供移动撤销。来源位置被占用或目标内容变化时拒绝覆盖；撤销后重新打开原目录继续整理。
- 中断操作先核对日志和实际文件。目标完整但来源仍在时，需要点击“核对并恢复”才清理已核实的来源。无法核实的记录保留，禁止继续执行新的移动或导出。
- “取消”停止尚未开始的文件，不回滚已完成项；单张裁剪导出期间不支持立即中断。

## 当前支持范围

| 项目 | 当前行为 |
| --- | --- |
| JPEG / PNG | 扫描、缩略图、大图、裁剪、旋转、移动、归档已验证 |
| WebP / BMP | 扫描及 Qt 解码入口已接入，未完成格式样本验收 |
| HEIC / HEIF | 可索引；本机解码兼容性未确认，失败时显示占位提示 |
| iPhone Live Photos | 同目录同主名照片与 MOV 标为待配对，阻止拆分移动和归档；元数据配对和单项展示待实现 |
| MP4 / MOV | 播放、暂停、声音、拖动进度及原文件移动入口已接入；真实编码兼容性待验证，网格使用占位图 |
| 目标目录 | 逐层展开/收起、含子目录总数、右键新建和重命名（含根目录）、任意层级接收文件、双击浏览直属媒体；目录移动、拖放待实现 |
| 编辑 | 多子图、预设比例、任意角度、草稿；编辑撤销重做、自定义比例预设和 JPEG 输出待实现 |
| 性能 | 后台任务、可视网格、缩放解码；尚无磁盘缩略图缓存及完整优先级调度，未完成千张以上实测 |

同名候选检查不能识别所有 Live Photos，当前不适合整批整理混合 Live 素材。跨卷复制的拍摄元数据/文件时间保留、色彩配置保留、输出撤销、磁盘断连与所有失败点恢复也未完整验收。

## 构建环境

| 组件 | 版本 / 位置 |
| --- | --- |
| Qt | 6.10.3，`.tools/Qt/6.10.3/mingw_64`，含 Multimedia、Image Formats |
| MinGW | 13.1.0，`.tools/Qt/Tools/mingw1310_64` |
| CMake / Ninja / aqtinstall | 4.4.4 / 1.13.2 / 3.3.0，见 `requirements-build.txt` |
| C++ | C++20，Release 构建 |

普通构建（克隆仓库后可直接使用）：

```powershell
.\Build.ps1
```

测试代码与测试配置仅在本地 `tests/` 中维护，不上传仓库。本地具备这些文件时可使用 `./Build.ps1 -Test`；普通构建默认关闭测试，也不要求 Qt Test 组件。

新开发环境安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m aqt install-qt windows desktop 6.10.3 win64_mingw -m qtmultimedia qtimageformats -O .tools\Qt
.\.venv\Scripts\python.exe -m aqt install-tool windows desktop tools_mingw qt.tools.win64_mingw1310 -O .tools\Qt
.\Build.ps1
```

程序使用项目中的 QML 文件和 Qt SDK，尚未制作独立安装包。需求与设计描述完整产品目标；已实现范围以本页和[开发进度](08-development.md)为准。
