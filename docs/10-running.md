# 功能版运行说明

## 启动与数据

完成依赖安装和构建后，在项目根目录双击 `Start.cmd`，启动 C++ 原生功能版。脚本自动配置本项目 Qt 运行环境，不需要手动写代码或启动 Python。`Preview.cmd` 仅用于静态 UI 演示，需安装 `requirements-preview.txt` 中的依赖。

应用内重启使用右上角“操作记录”左侧的“重启应用”。点击后先保存当前裁剪草稿和浏览记录，再启动替换进程；无需重新寻找启动脚本。新进程沿用数据目录与运行环境，等旧进程退出并释放数据锁后加载当前批次、界面模式和草稿。文件操作进行中、弹窗打开或正在重启时禁用该入口。保存或启动准备失败时保留当前窗口并显示原因，可修正后重试。重启不会自动执行移动、复制或导出。

功能版使用真实文件：移动会更改文件位置，复制保留来源；仅裁剪生成子图并保留原图；单子图可覆盖原图，多子图可全部保存并校验后回收原图，裁剪结果统一留在原目录。

浏览范围、批次、草稿、操作日志及全局偏好统一保存在 `%LOCALAPPDATA%\ImageClassifier\ImageClassifier\library.sqlite`；全局偏好使用其中的 `settings` 表，界面模式键为 `viewMode`（`batch` / `large`）。同一数据目录只允许一个实例。测试可通过环境变量 `IMAGECLASSIFIER_DATA_DIR` 指定隔离数据目录。运行日志位于项目根目录 `app.log`、`app-error.log`。

## 使用流程

右上角“设置”集中管理浏览模式、缩略图大小、批次数量、默认扫描子目录、大图缩略栏和智能裁剪。更改自动保存，点击“返回整理”或按 Esc 返回原工作区；默认值与生效范围见[设置与全局偏好](13-settings.md)。

1. 点击顶部“来源”，选择目录，或每行输入一个目录后添加；可设置是否递归读取。扫描只建立清单，图片按需解码。
2. 首次在左侧选择归类目录；标题旁的刷新图标统一更新目录与图片，更换根目录位于“…”菜单。单击任意目录即可作为归类位置，包括含子目录的父节点；右键具体目录可新建子目录、重命名或在资源管理器中打开。
3. 批量模式中单击图片可选择或取消。从图片按住左键拖动，按显示顺序连续多选；从网格空白处起拖则按矩形框选。松开后保留，原有选择不受影响，按 Esc 撤回本次拖选。拖到上下边缘会自动滚动。“取消选择”可取消全部选择；若筛选隐藏了部分选择，底部显示隐藏数量，点击可只取消隐藏项。选择完成后单击目标目录，再点击底部归类按钮。已移动项移出当前批；处理完当前批后自动准备下一批。
4. 大图模式继承上次的裁剪开关。开启时拖动四角或四条边调整区域、拖动内部移动区域；选择比例或输入角度微调。双击图片围绕点击位置放大铺满画布，再次双击恢复适合窗口；Ctrl + 滚轮围绕鼠标缩放。放大后按住鼠标中键拖动画面，浏览模式也可直接左键拖动。
   底部缩略栏可点击切图，用滚轮或两侧按钮横向浏览；当前图片高亮，切图自动保存草稿，左右方向键也可切换。
   安装本地模型后可勾选“智能模式”，新图片自动应用人物裁剪建议；手动草稿保留，可点击“重新推荐”。勾选状态会持久化，完整规则见[本地智能裁剪](12-smart-crop.md)。
5. 右侧顶部添加和切换裁剪区域，各区域独立调整比例、位置及角度。所有结果留在原图目录：“仅裁剪”生成子图并保留原图；单子图可“裁剪并覆盖原图”，多子图可“裁剪并删除原图”。覆盖或删除完成后选中生成的结果。JPG／PNG 覆盖保持原格式，其他格式转为 PNG；Live 裁剪为静态图片并回收原动态成员。需要归类时关闭“裁剪 / 旋转”，选择左侧目标，点击“移动”或“复制”。
6. 需要继续调整已归类图片时，双击目录或右键选择“打开此目录”，仅读取直属文件。单击目录仅选择归类目标，保留当前工作目录和多选；双击浏览会撤回首次单击的目标变化。工作目录标记“工作”，归类目标以背景高亮。软件不要求设置“已完成 / 待细分”业务状态。

刷新图标或 F5 更新文件版本及目录数量，保留当前筛选、选择和浏览位置；新文件进入后续队列，可通过“再加入 N 项”加入。大图移走当前图片后优先切到相邻下一张，末项移走时回到前一张。加载失败可点击“重新加载”；没有图片时显示添加来源、清除筛选或刷新入口。

批量工作区 Ctrl+A 选择当前筛选结果，Esc 清空选择；输入文字或打开弹窗时保留原生文字编辑操作，不触发后台选择或切图。设置页 Esc 返回整理；完整快捷键作用域见[操作流程](02-workflow.md)。

批次默认 100 项，可在“设置 → 浏览与批次”中设置 10—500 项，对下一批生效。边界相似时逐项延伸，自动上限为目标数量的两倍；不确定时提示，有后续图片时可点击底部“再加入 N 项”扩展当前批。判断使用缩小图的差异哈希和颜色距离，尚未经过真实图库校准。

底部数量提示旁的红色垃圾桶用于直接删除：批量模式处理所有已选项（包括被筛选隐藏的选择），大图模式仅处理当前项。确认后移入 Windows 回收站，Live 图包含配套视频；不导出裁剪区域，已保存的子图不受影响。无需选择目标目录，可在操作记录查看结果，恢复文件请使用系统回收站。

未处理图片保留在当前列表中，不提供隐藏或跳过操作。切图及退出时保存编辑草稿；重启恢复当前批并自动后台核对磁盘，更新外部修改、删除及恢复的文件。原图从回收站恢复到原位置后会重新显示，无需双击目录重开；也可点击刷新或按 F5 核对。原有批次及有效草稿保持，其他新增文件进入待加载队列。批量／大图模式和裁剪模式各自保存，跨目录、重启均保持上次选择；首次启动默认批量模式、裁剪模式开启。关闭裁剪模式后，大图只浏览图片，再次开启仍可继续已有草稿。当前光标位置不持久化。

## 输出与文件操作

Live 图默认展示封面，点击卡片或大图右上角的同心圆实况图标循环播放，默认静音，旁边的声音按钮可开启音轨；再次点击停止并回到封面和原有裁剪草稿。iPhone 的照片和配套视频在同一目录中按关联标识自动合并展示，移动、复制和撤销会处理完整的一组文件。

普通视频点击网格中的播放三角形进入大图播放；在大图中单击画面即可暂停，再单击继续。视频默认静音，右上角声音按钮可开启声音；声音和进度控制不会触发画面的播放／暂停动作。

- 子图按原图像素计算，独立子图输出 PNG，原位覆盖保留 JPG／PNG 格式。裁剪框限制在旋转后的实际图像四边形内；旋转或恢复旧草稿时自动收紧越界区域，拖动及缩放会停在边界。导出前校验全部子图，拒绝越界参数，不输出旋转产生的空白角。原 PNG 自身的透明内容仍保留。
- 未启用智能模式时默认裁剪区域为中心 80%，旋转后可能缩小，以当前画面中的裁剪框为准。四角和四条边均可拖拽缩放，拖动框内可移动；角点的可点击区域为 28×28 个逻辑像素，四边提供宽 20 个逻辑像素的命中区域。固定比例时拖边会联动另一方向尺寸，并保持旋转边界约束。
- 仅裁剪保留原图；覆盖后选中替换结果，多子图删除原图后优先选中生成的子图。“移动”始终移动完整文件，不应用裁剪框；对子图也可直接移动。复制或仅裁剪后原图仍在当前批，继续整理即可。
- 重名文件自动添加数字后缀，不覆盖目标。已成功的子图输出通过固定编号校验，原参数重试复用有效输出。
- “操作记录”提供移动撤销。来源位置被占用或目标内容变化时拒绝覆盖；撤销后重新打开原目录继续整理。
- “操作记录”右上角的“清空记录”经确认后清空全部已结束记录，包括未在最近 100 项中显示的旧记录；清空后无法再从界面撤销这些移动。图片、视频、目录及草稿保持不变，未完成操作继续保留，无可清空记录或正在执行任务时按钮禁用。
- 中断操作先核对日志和实际文件。移动操作目标完整但来源仍在时，需要点击“核对并继续”才清理已核实的来源。复制操作始终保留来源。无法核实的记录保留，禁止继续执行新的移动、复制或导出。
- “取消”停止尚未开始的文件，不回滚已完成项；单张裁剪导出期间不支持立即中断。

## 当前支持范围

| 项目 | 当前行为 |
| --- | --- |
| JPEG / PNG | 扫描、缩略图、大图、裁剪、旋转、移动、复制、仅裁剪已验证 |
| WebP / BMP | 扫描及 Qt 解码入口已接入，未完成格式样本验收 |
| HEIC / HEIF | 安装媒体组件后支持封面、缩略图和静态裁剪；iPhone 15 Pro HEIC 样本已验证 |
| 单文件 JPEG 实况图 | MicroVideo / MotionPhoto 元数据识别、封面、循环播放、静音开关、完整文件移动复制；微信导出样本已验证 |
| iPhone Live Photos | 同目录唯一内容标识配对、单项展示、播放、成组移动/复制/撤销及中断恢复；不唯一或缺失成员时阻止修改 |
| MP4 / MOV | 网格封面与播放三角形、大图播放前封面、底部缩略栏、播放/暂停及进度跳转；仅点击播放时才加载播放器文件，停止、切图、退出大图及文件操作前释放播放源；默认静音，画面右上角可开启声音，切换视频或重新进入大图恢复静音；两段微信 HEVC MP4 与 iPhone MOV 样本通过取帧和播放检查，更多编码兼容性待验证 |
| 目标目录 | 逐层展开/收起、含子目录总数、右键新建和重命名（含根目录）、任意层级接收文件、双击浏览直属媒体；目录移动、拖放待实现 |
| 编辑 | 多子图、预设比例、任意角度、草稿，原位覆盖支持 JPG／PNG；编辑撤销重做、自定义比例预设和独立子图的可选输出格式待实现 |
| 性能 | 后台任务、可视网格、缩放解码、内存及磁盘缩略图缓存、大图相邻预览预载；完整优先级调度及千张以上性能仍待验收 |

Live 支持范围不包含 LIVP 压缩包、所有厂商私有单文件格式或跨目录配对。跨卷复制的文件时间保留、色彩配置保留、输出撤销、磁盘断连与所有失败点恢复仍需完整验收。

## 构建环境

| 组件 | 版本 / 位置 |
| --- | --- |
| Qt | 6.10.3，`.tools/Qt/6.10.3/mingw_64`，含 Multimedia、Image Formats |
| MinGW | 13.1.0，`.tools/Qt/Tools/mingw1310_64` |
| CMake / Ninja / aqtinstall | 4.4.4 / 1.13.2 / 3.3.0，见 `requirements-build.txt` |
| C++ | C++20，Release 构建 |

普通构建（克隆仓库后可直接使用）：

```powershell
.\Setup-Media.ps1
.\Build.ps1
```

`Setup-Media.ps1` 安装 ExifTool 与 HEIC 解码动态库并校验固定 SHA-256，首次安装需要联网，使用时完全离线。媒体依赖及许可说明见[媒体支持](03-media.md)。Windows 需有 Microsoft Visual C++ 2015—2022 x64 运行库供 HEIC 解码库使用。

测试代码与测试配置仅在本地 `tests/` 中维护，不上传仓库。本地具备这些文件时可使用 `./Build.ps1 -Test`；普通构建默认关闭测试，也不要求 Qt Test 组件。

新开发环境安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m aqt install-qt windows desktop 6.10.3 win64_mingw -m qtmultimedia qtimageformats -O .tools\Qt
.\.venv\Scripts\python.exe -m aqt install-tool windows desktop tools_mingw qt.tools.win64_mingw1310 -O .tools\Qt
.\Build.ps1
```

程序使用项目中的 QML 文件和 Qt SDK，尚未制作独立安装包。需求与设计描述完整产品目标；已实现范围以本页和[开发进度](08-development.md)为准。

可选智能裁剪模型通过 `./Setup-AI.ps1` 安装；安装完成后分析和训练离线运行。运行资产、学习目录及磁盘占用见[本地智能裁剪](12-smart-crop.md)。
