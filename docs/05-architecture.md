# 技术架构

## 技术栈

采用 C++、Qt 6、Qt Quick/QML、Qt Multimedia、SQLite 和 CMake。图片读取使用 Qt 接口，局部视觉特征按需引入 OpenCV；HEIC 解码组件通过目标素材验证后锁定。依赖具体版本在可重复构建中固定，核心功能不依赖独立显卡或云服务。

## 模块职责

| 模块 | 责任 | 边界 |
| --- | --- | --- |
| QML 界面 | 目录树、虚拟化网格、编辑、播放器、边界提示 | 不直接扫描磁盘或执行重计算 |
| 应用服务 | 命令协调、校验、进度与结果通知 | UI 通过资产编号发命令，不操作裸路径 |
| 目录索引 | 文件清单、身份、版本、元数据、外部变化 | 文件系统决定实际位置 |
| 媒体服务 | Live 配对、解码、代表帧、缩略图 | 一项资产可含多个文件 |
| 批次调度 | 稳定排序、游标、快照、边界延伸 | 当前批开始后不自动重排 |
| 边界检查 | 相邻小图特征与三态判断 | 算法和参数可替换，无全库聚类依赖 |
| 编辑服务 | 草稿、坐标变换、子图输出 | 预览与导出采用一致变换 |
| 文件服务 | 移动、目录维护、归档、撤销与恢复 | 所有文件修改经过持久操作记录 |
| 存储服务 | SQLite、事务、迁移、查询 | 单写入队列，不把数据库事务当文件事务 |
| 后台执行器 | 限流、优先级、取消、资源预算 | 可见内容优先，结果回 UI 线程更新 |

## 数据模型

| 实体 | 关键内容 |
| --- | --- |
| Project | 来源根、目标根、归档位置、设置、数据库结构版本 |
| MediaAsset | 稳定编号、类型、代表静态图、尺寸或时长、可用性 |
| AssetFile | 资产编号、成员角色、路径、文件身份、版本、配对标识 |
| BoundaryFeature | 资产与文件版本、算法版本、特征和计算结果 |
| BrowseSession | 当前范围、递归、排序、游标、已处理项清单 |
| Batch、BatchItem | 成员快照、边界依据、用户调整、执行进度 |
| EditDraft、Derivative | 父资产、版本、变换、目标、输出资产 |
| DirectoryNode | 目录编号、父节点、实际路径、可用性 |
| Operation、OperationItem | 组级和文件级意图、输入输出、校验、进度、撤销关联 |

路径定位文件，内部编号识别资产，内容哈希核对数据，三者不能互相替代。相同内容的独立副本不合并；Live 配对由成员关系表达。

BrowseSession 只用于恢复，已处理并移出当前批的记录不永久屏蔽文件；未处理图片保持可见。查询使用分页和索引；操作编号保证幂等，数据库迁移前备份业务数据。草稿和日志不是可丢弃缓存。

## 资源与线程

网格按需创建可见项并复用显示对象。缩略图落磁盘，内存采用有容量上限的缓存；缓存键包含资产、成员文件版本、尺寸与编辑版本。文件变化令相关缓存和特征失效。

图片解码、视频取帧、文件写入各自限流；优先级为当前预览、可见缩略图、当前边界、有限预取。取消过期任务并丢弃过期结果，限制排队数量及未消费结果，不能只限制并发线程数。

旋转预览复用 EXIF 方向纠正后的图片纹理，通过 Qt Quick 场景变换实时更新角度，不因角度变化重新解码。原图中心在旋转画布中的位置、画布尺寸及裁剪约束由共享几何计算提供，保留 Qt 导出变换的像素取整偏移。保存草稿的延迟不影响画面更新。

CPU 像素、GPU 纹理、播放器分别设资源预算。读取尺寸后预估成本，尽量按目标尺寸解码；不支持低成本解码的大素材应降级或报错，不能耗尽内存。性能目标见[验收标准](07-acceptance.md)。
