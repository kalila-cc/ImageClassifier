# 功能版验证结果

## 环境与结论

验证对象：原生功能版 0.1.0；Windows 本机、Qt 6.10.3、MinGW 13.1.0、Release 构建。核心自动化测试和已列出的原生窗口流程通过。尚未完成产品 A1—A23 全量验收。

测试使用临时目录、生成图片及项目示例图片副本，不操作用户素材。可重复命令：在项目根目录执行 `./Build.ps1 -Test`。测试实现位于 `tests/core_tests.cpp` 和 `tests/ui_tests.cpp`，CTest 日志位于 `build/Testing/Temporary/LastTest.log`。

## 原生窗口检查

共享控件的离屏交互检查通过：普通、弱化、已选中及主按钮的正常/悬停/按下背景可区分，悬停显示手型；禁用按钮不响应点击且不显示手型；数字加减正常，弹窗确认与取消各触发一次并关闭。图片选择层将悬停和按下状态传递给卡片；图片起拖显示连续范围高亮，空白起拖显示矩形选框和十字光标。相关选择回归检查全部通过。

按钮的背景和手型由同一悬停区域控制，点击交给原生 Button 处理。悬停背景直接切换，不执行透明色渐变，保证侧栏浅色背景下的反馈清晰稳定。侧栏按钮及目录行的悬停反馈持续显示；启动日志无 QML 错误。

横向工具按钮间距为 8 逻辑像素，弹窗操作按钮间距为 12 逻辑像素并靠右对齐。普通主操作使用绿色；归档原图、撤销移动、恢复文件操作和取消任务使用琥珀色提示；移除子图使用红色，并通过文字及悬停说明区分关闭面板与移除裁剪草稿。原生窗口已检查弹窗和大图工具面板的布局，按钮悬停、点击及确认/取消语义回归通过。

批量选择另有离屏 QML 交互测试：`./.venv/Scripts/python.exe tests/test_grid_selection.py`，使用 `requirements-preview.txt` 中的 PySide6 环境。覆盖单击切换、连续拖选及缩小选区、跨越起点反向、五列网格 02—14 连选、保留原有选择、筛选列表顺序、末行空白边界、空白起拖框选、松开后停止、Esc 撤回、跨屏自动滚动、滚轮滚动及双击打开。测试不移动桌面鼠标，不操作用户文件。

隔离工作区：`test-results/ui-fixtures`，状态目录为其下的 `state`。
