# 产品与设计评估

## 评估目标

归图的核心价值是快速决定素材去向，以及减少人像裁剪的重复操作。界面应让用户始终清楚“正在看什么、正在编辑哪个裁剪区域、操作影响哪些文件、文件将去哪里”。设计优先保证操作连续、范围可见、失败可恢复，再增加功能。

## 产品经理视角

| 优先级 | 用户需要 | 当前实现 | 验证关注点 |
| --- | --- | --- | --- |
| P0 | 看清移动与裁剪的文件去向 | 底部明确原文件移动目标；工具区显示当前裁剪区域的独立目标；仅裁剪保存到原目录 | 多区域不同目标、选回已有区域、原图移动与裁剪输出互不混淆 |
| P0 | 刷新后继续当前工作 | 更新文件版本与缩略图，保留筛选、现存选择和浏览顺序；新文件留在后续队列 | 外部修改、缺失、恢复、追加文件，旧草稿不被当作新版本 |
| P0 | 了解所有将被移动的文件 | 底部显示筛选隐藏的选择数量，并允许只取消隐藏选择 | 搜索和媒体筛选后移动范围仍可理解 |
| P1 | 连续处理图片 | 移走当前图后优先显示原顺序下一张；末项回到前一张 | 连续移动、中间移除、最后一张及整批清空 |
| P1 | 浏览目录不改变编辑决定 | 单击立即选目标；双击浏览撤回第一次单击造成的目标变化 | 草稿目标、原图移动目标和工作目录分别保持正确 |
| P1 | 遇到空目录或坏图仍有明确操作 | 两种模式共用空状态；预览失败提供重新加载入口，禁用裁剪输出 | 空来源、零搜索结果、损坏或被外部移动的图片 |

完整文件安全仍是发布前提。现有校验与恢复测试不能代替真实跨磁盘、断连、权限变化及磁盘满条件的验证。

## 设计师视角

界面采用摄影工作台的视觉层级：石墨色顶栏承载全局导航，中性深色画布突出图片，浅灰目录与工具面板保持清晰的阅读对比。青绿仅用于选择状态与主操作，危险操作使用红色，范围提醒与恢复使用琥珀色；颜色均配合文字或图标表达含义。

| 类别 | 视觉规范 |
| --- | --- |
| 布局 | 顶栏 60px、左侧目录 220px、右侧工具 268px；以 1120×720 为最小可用窗口，图片占据剩余空间，多子图与工具内容超出时可滚动访问 |
| 文字 | 常用文字 13px、分组标题 14px，通过字重与中性灰区分主次；避免整片文字染成强调色 |
| 图标与控件 | 使用统一线性图标、细边框与圆角；按钮、输入框与菜单统一提供悬停、按下、禁用和键盘焦点状态 |
| 裁剪检查器 | 智能建议、裁剪区域、画幅比例与旋转分组排列；比例每行最多三个，默认透明、选中使用圆角背景；目标目录单独展示，完整路径可悬停查看 |
| 范围与反馈 | 原文件与子图目标保持明确；空态、加载及错误态各有可读提示与可执行动作，低频说明不挤占图片空间 |

视觉验收应同时核对最小窗口、常用窗口、长路径与多子图状态；功能用例通过不等同于最终视觉验收完成。

## 文案与图标语义

文案描述用户要完成的动作及文件后果。图标辅助识别，不代替关键动作文字；图标按钮提供悬停说明与无障碍名称。

| 场景 | 统一表达与行为 |
| --- | --- |
| 编辑与输出 | 导出前称“裁剪区域”，可添加、切换和移除；导出产生的图片文件称“子图” |
| 仅裁剪 | 将所有裁剪区域导出为子图，保存在原图目录并加入列表；保留原图，便于稍后分别归类 |
| 裁剪并覆盖原图 | 仅单子图显示，以验证后的裁剪结果替换原文件，旧原件移入回收站 |
| 裁剪并删除原图 | 仅多子图显示，全部子图保存至原目录并校验后回收原文件 |
| 移动 | 将完整原文件移到所选目标目录，不应用裁剪区域；内容校验一致后移除原位置的文件。使用目录与右箭头图标，区别于前后浏览箭头 |
| 移除裁剪区域 | 使用中性的圆圈减号；只移除当前区域，不删除原图或已导出的文件，不使用垃圾桶图标 |
| 目录入口 | “浏览此目录”在归图中显示该目录的直属图片或视频；“打开所在目录”在系统文件资源管理器中打开当前文件所在目录，使用打开文件夹图标 |
| 视频播放 | 播放中显示暂停图标及“暂停”说明；暂停或停止时显示播放图标及“播放”说明，与实际播放状态一致 |
| 预览缩放 | “适合窗口”为缩放基准；倍数表示相对适合窗口的大小，点击恢复适合窗口，避免被理解为原始像素倍率 |
| 操作记录 | “核对并继续”校验文件并接续未完成的操作；“撤销移动”才将文件移回来源位置，使用撤销箭头，二者不混称“恢复” |
| 弹窗动作 | 创建与改名分别标为“新建”“重命名”，退出而不执行标为“取消”；来源目录和操作记录弹窗使用“关闭”，普通提示使用“知道了” |

## 后续优先级

| 优先级 | 建议 | 完成标准 |
| --- | --- | --- |
| P0 | 完整验证文件与恢复边界 | 临时素材上覆盖跨盘、磁盘满、权限变化、路径被外部改动及中断恢复，无内容丢失或错误成功状态 |
| P1 | 完善 iPhone Live Photos 与 HEIC | 使用真实导出样本核对元数据配对、缺失与歧义；成组展示和移动，验证解码兼容性 |
| P1 | 建立大量素材性能基线 | 在 1000、5000、10000 项下记录首屏、滚动帧时间、交互 P95、峰值内存和后台并发；结果与硬件、素材类型一起保存 |
| P1 | 评估智能裁剪实际收益 | 分别统计上半身、下半身、全身、多人、遮挡的建议接受率、平均调整次数和建议耗时；用未参与学习的素材评估 |
| P1 | 支持编辑撤销与重做 | 拖拽、旋转、比例、添加及移除裁剪区域可明确撤回，且与文件移动撤销区分 |
| P2 | 完善批次边界人工核对 | 不确定时提供边界双图比较；测量误切与误纳入，确认不会为了等待全库分析阻塞首批 |
| P2 | 完善色彩、输出与视频预览 | 真实 EXIF/ICC 样本、JPEG 质量控制、视频代表帧及常用编码验证 |

实现进度与证据统一维护在[开发进度](08-development.md)及[验证结果](11-validation.md)。离屏截图用于核对布局与状态，不能单独证明真实显示缩放、长时间使用或图库准确率已达标。
