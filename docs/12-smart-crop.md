# 本地智能裁剪

## 使用规则

大图模式的裁剪面板提供“智能模式”勾选项，设置持久化保存，重启后保持。默认关闭。开启后，在裁剪模式中打开尚未调整的新图片时自动分析人物，将建议直接应用到当前可编辑的裁剪框。关闭裁剪模式时不发起新建议并忽略尚未返回的旧建议，智能模式勾选保持不变。已有手动草稿保留；点击“重新推荐”可主动生成新的建议。

建议只调整当前子图的区域，不改变旋转角度、固定比例或输出目录。可以继续拖动四角、移动、旋转、修改比例，也可以添加子图并分别归类。修改比例或角度后，需要新建议时点击“重新推荐”。

手动操作开始、切换图片或子图、关闭智能模式、退出大图模式、开始文件操作后，旧请求的结果不再覆盖界面。没有可靠人物检测结果、模型不可用或计算失败时保留当前框，并在面板显示原因。视频及待配对的 Live Photos 不参与智能裁剪。

## 裁剪完成记录

“仅裁剪”“裁剪并覆盖原图”或“裁剪并删除原图”的全部输出完成后产生一条学习记录：本次所有子图成功落盘并通过校验，且来源版本通过校验。覆盖操作使用替换前解码的原始图片与最终区域学习；多子图删除在保存学习样本后回收原文件。一次导出多个子图仍算一条操作记录，内部包含各子图的最终区域、比例和旋转参数。智能模式关闭时，成功的手动裁剪同样记录。

拖动过程、仅保存草稿、失败的导出和普通文件移动或复制不产生学习记录。相同输出操作在最近记录中按操作编号去重，重复点击不会重复学习。学习记录写入失败不会回滚已成功的图片输出，界面会明确提示记录未保存。

最近目录最多保留 100 条操作记录。提交新记录后删除最早的记录及其图片和分析缓存，不删除用户的原图或导出子图。每条记录保存一张已校正 EXIF 方向、最长边不超过 1280 像素的 JPEG 原图副本；小图不放大。训练不依赖原图继续存在。

默认目录：

```text
%LOCALAPPDATA%\ImageClassifier\ImageClassifier\smart-crop\
  recent\r-时间-编号\
    source.jpg       学习用缩小原图
    record.json      一次操作及其全部子图的裁剪参数
    analysis.json    人物、关键点与视觉特征缓存
  preferences.json  个人裁剪偏好参数
  staging\          尚未提交的记录
  requests\         当前推理的临时图片
```

“打开记录目录”打开当前实际的 `recent` 目录。指定 `IMAGECLASSIFIER_DATA_DIR` 时，学习目录随应用数据目录移动。图片分析和训练均在本机完成，不上传图片。

## 模型与学习

| 组成 | 作用 | 模型文件大小 |
| --- | --- | --- |
| YOLOX-m | 检测图片中的人物 | 约 97 MiB |
| RTMPose-l | 提取人物关键点，辅助判断取景范围 | 约 106 MiB |
| DINOv2-small | 提取画面特征，检索相似裁剪经验 | 约 84 MiB |
| 个人偏好模型 | 按人物相对坐标学习区域，区分紧凑人像、半身及全身取景 | 远小于 1 MiB |

视觉模型保持固定权重；持续学习发生在本地案例检索和带正则化的轻量回归模型中，不反复训练整个视觉网络。新记录分析后立即进入相似案例检索；同一取景类别累计至少 5 次有效操作后可批训练，并随新增记录更新。不同子图作为独立标签，同一操作的训练总权重保持一致，避免一次导出很多子图被重复放大。达到 100 条后，更新仅使用当前保留的记录。

预测结合相似画面、人物位置和关键点、当前比例及旋转角度，给出候选区域。无历史时根据人物位置取景；多人图默认优先主要人物，手动调整过的框可为“重新推荐”提供主体线索。预测最终经过与手动编辑相同的旋转有效区域约束和导出像素校验。

记录已保存不代表必然能训练出有效人物偏好：无法可靠检测人物的记录仍保留，但不进入人物回归。视觉相似不等于用户意图一致，遮挡、多人、特殊构图和紧贴画面边缘的人物仍可能需要手动调整。自动建议不自动执行导出。

## 安装与资源

模型为可选组件。克隆仓库、构建程序、启动应用或打开设置页均不下载模型。未安装时，编辑区“智能模式”“重新推荐”及设置页的智能裁剪开关置灰；浏览、归类、旋转和手动裁剪正常可用，成功裁剪仍保存近期学习记录。

在已具备项目构建环境的电脑上，打开 **设置 → 裁剪与智能 → 安装模型**。页面展示“未安装 / 安装中 / 已安装 / 安装失败”，安装期间显示当前阶段。安装完成并通过检查后，控件自动恢复可用，首次安装不自动开启智能模式；已有智能偏好保留。失败时可点击“重试安装”，并通过“打开日志目录”查看 `install.log`。

安装由独立后台进程执行，用户可继续整理，关闭或重启归图不会中断安装。再次打开时从持久状态恢复显示。单个模型目录只允许一个安装任务；意外中断不会显示为已安装，需要用户主动重试。安装状态保存在模型根目录的 `install-state.json`，不与图库数据混用。

开发者也可主动执行同一安装脚本：

```powershell
.\Setup-AI.ps1
```

脚本下载固定版本的模型和运行依赖，校验人物及关键点模型的 SHA-256，并加载检查全部 ONNX 模型。DINOv2 首次安装使用固定上游版本导出 ONNX；成功后清理仅供导出使用的 PyTorch 环境和缓存。开发者需要保留导出工具时使用 `-KeepExportTools`。

运行资产默认位于 `.tools/smart-crop`，也可通过 `IMAGECLASSIFIER_AI_HOME` 指定位置；模型约 287 MiB，推理环境约 234 MiB，合计约 521 MiB，另加最近记录。首次安装过程中临时导出环境和缓存约占 1.5 GiB。使用 ONNX Runtime CPU 推理、4 个计算线程，不要求独立显卡或 CUDA。后台独立进程处理模型计算，前台继续编辑。

上游来源：[YOLOX](https://github.com/Megvii-BaseDetection/YOLOX)、[MMPose](https://github.com/open-mmlab/mmpose)、[RTM 库及推理参考](https://github.com/Tau-J/rtmlib)、[RTMPose 模型镜像](https://huggingface.co/Tau-J/RTMPose)、[DINOv2-small](https://huggingface.co/facebook/dinov2-small)。模型和运行依赖不纳入 Git；分发安装包时须附对应上游许可及第三方声明。
