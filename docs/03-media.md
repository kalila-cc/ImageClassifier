# 媒体支持

## 格式与降级行为

| 媒体 | 支持行为 | 验证重点 |
| --- | --- | --- |
| JPEG、PNG | 缩略图、预览、移动、裁剪、旋转 | EXIF 方向、透明通道、色彩与大尺寸 |
| HEIC/HEIF | libheif 解码封面、缩略图、旋转及静态裁剪 | 媒体组件安装、方向、真实导出文件；超大图及色彩仍需扩展验证 |
| 单文件 JPEG 实况图 | 识别 MicroVideo 和标准 MotionPhoto XMP，封面展示、循环播放、完整文件移动与复制 | 内嵌视频边界和容器校验；微信导出样本已验证 |
| iPhone Live Photos | 按照片与 MOV/MP4 的内容标识配对，单项展示、动态播放、成组移动/复制/撤销 | 同目录唯一配对、成员缺失、标识重复、重名和中断 |
| MP4、MOV 视频 | 缩略图、时长、播放、进度跳转、原文件移动 | 容器内实际编码、方向、声音和播放兼容性 |

文件扩展名不代表编解码兼容性。不能预览的素材保留占位卡片、类型、错误和外部打开入口；仍允许明确识别的独立文件移动，不自动删除。未明确支持的其他格式在扫描结果中列出。

## 图片缩略图

批量网格与大图底部缩略栏均按实际显示比例生成居中铺满缩略图。长图从原图中间区域提取细节，不先把整张图片压成很窄的小图再放大；显示位置与裁切方式保持一致。JPEG 优先使用区域解码，其他格式在资源预算内读取足够清晰的图片再裁切；保留 EXIF 方向和 PNG 透明通道，不修改原文件。缩略图最终输出最长边不超过 1024 像素。

图片缩略图使用两级缓存：解码后的内存缓存上限为 128 MiB，本地 PNG 缓存上限为 512 MiB，存放在应用数据目录的 `cache/thumbnails-v1/`。缓存键包含原文件路径、大小、修改时间、缩略图尺寸及算法版本；原文件变化后重新生成，文件不存在时不返回旧缓存。内存按最近使用顺序淘汰，磁盘达到上限后清理较旧的缓存文件。缓存损坏或无法写入时回退到原图解码，失败结果不缓存，原始媒体始终不受影响。

批量网格预加载可见区域前后约一屏的卡片，并保持虚拟化。调整缩略图尺寸时可保留同一图片的旧预览，切换素材时不沿用另一图片的画面；加载提示延迟 150 毫秒出现，避免快速缓存命中时闪烁。首次加载和超出缓存容量的素材仍可能短暂显示占位。

## Live Photos 配对

一个 Live Photo 是一个媒体资产，可对应静态照片和配套视频两个物理文件。网格展示一张带 Live 标记的卡片，计一个批次名额；静态预览使用照片，播放使用关联视频。已配对的视频不再作为普通视频重复入队。

大图底部缩略栏中的 Live 图片在右上角显示同心圆 SVG 标识，使用浅色半透明背景，不显示 LIVE 文案。该标识仅提示媒体类型，点击仍只切换图片，不触发播放。

ExifTool 读取照片的 Apple ContentIdentifier 和视频的 QuickTime ContentIdentifier。同一目录中只有一张照片与一个视频共享标识时才确认配对，文件名可以不同。同名照片与 MOV 只构成候选；缺失成员、标识冲突或多个副本时提示待配对并阻止修改，不凭文件名自动猜测。手动配对、跨目录配对及 LIVP 压缩包尚未提供。扫描结果按文件路径、大小和修改时间缓存，文件变化后重新读取。

移动、复制和撤销以完整资产为单位，保留成员内容及配对元数据。重名时照片和视频使用相同的新主名；操作前持久化完整计划，逐文件校验 SHA-256，全部成员成功才报告整个素材成功。中断后保留组级记录，用户从操作记录继续；目标被外部修改时拒绝恢复。撤销恢复两个成员原先各自的文件名。未知伴随文件不自动删除。

从 Live 静态部分裁剪时，导出普通静态子图，原照片和配套视频保留原位置；需要移动或复制时按完整资产处理。裁剪与归类规则见[图片编辑](04-editing.md)，多文件中断处理见[文件安全](06-file-safety.md)。

## 视频与资源使用

普通视频默认静音，有音轨时在画面右上角显示声音按钮，可手动开启或关闭。大图模式单击视频画面切换播放／暂停，暂停时显示居中播放按钮；声音按钮、进度条及底部缩略栏独立响应，不触发画面点击。暂停与继续播放保留当前声音选择；切换视频、离开大图或停止当前浏览后恢复静音，不把上一段视频的声音选择带到下一段。

普通视频在网格中展示真实封面和居中的播放三角形。点击三角形进入大图并播放，卡片其他区域保留单击选择与双击打开行为；大图播放前和底部缩略栏同样显示封面。封面提取失败时显示“封面暂不可用”，仍可尝试播放。取帧在后台进行，不输出声音；取得一帧后释放解码器，等待上限为 4 秒。成功封面按文件路径、大小及修改时间缓存在内存中，上限 32 MiB，最长边 960 像素，供各视图缩放复用；不扫描解码整段视频。

Live 图默认显示封面。批量卡片及大图画布右上角使用同心圆与点状外环组成的 SVG 实况图标，不显示 LIVE 文案，按钮采用浅色半透明背景。点击开始循环播放，播放时使用主题色选中态，准备期间仅图标旋转，悬停与无障碍说明提供播放、取消准备或停止操作提示。默认静音，有音轨时显示独立声音开关；再次点击实况图标停止并返回封面，重新播放恢复静音。播放按钮不改变批量选择，也不触发双击打开。切换模式、打开设置、换图或执行文件操作时停止播放；播放期间暂时隐藏裁剪交互，停止后恢复草稿和裁剪模式偏好。

视频归类保持原文件，不转码、不剪辑。只有主动播放的 Live 图创建解码器，同一时间最多一个。预览使用临时视频副本，不修改或拆分源文件；后台提取只允许一个任务，并取消过期请求。内嵌或配套视频超过 256 MB 时拒绝预览。应用正常退出清理临时文件。

边界检查可使用视频代表帧与时间作为辅助，不能以单帧推断整段视频内容。代表帧获取失败时进入不确定判断，不将视频全片解码分析。

Qt Multimedia 负责播放，图片解码单独处理。视频 HEVC 可播放不意味着静态 HEIC 一定可读；两者独立验证并随安装包交付必要组件。

## 媒体组件

运行 `Setup-Media.ps1` 后重新构建，安装带 SHA-256 校验的 ExifTool 13.59 与 libheif 1.23.5 及其动态库依赖。ExifTool 通过独立只读进程批量读取指定标签，libheif 通过 C 接口解码，Qt Multimedia 负责播放；不引入浏览器内核。媒体组件、许可证和测试素材均保存在本地 `.tools/`，不提交二进制到仓库。

libheif 与 libde265 采用 LGPL，OpenJPEG 和 OpenH264 的许可文件保存在 `.tools/media/licenses/`；ExifTool 保留发布包附带的许可文件。发布安装包时须附许可、对应源码获取方式及必要运行库，并保持动态库可替换。当前二进制来自 [Qt HEIC 插件项目的 v0.7.3 发布附件](https://github.com/novomesk/qt-heic-image-plugin/releases/tag/v0.7.3)，只使用其解码库，不加载该项目的 Qt 插件。

GitHub 组件评估：[libmotionphoto](https://github.com/google/libmotionphoto) 提供 C++ 格式解析，但当前 Windows 接入仍需移植；[live-photo-component](https://github.com/Feirobot/live-photo-component) 面向 Web Component。归图采用 [ExifTool](https://github.com/exiftool/exiftool)、[libheif](https://github.com/strukturag/libheif) 与 Qt Multimedia，单文件 JPEG 的 XMP 和视频范围由本地适配层校验。
