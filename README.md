# 归图 · ImageClassifier

Windows 本地图片与视频归类工具，采用 C++ / Qt 6 / QML / SQLite。

## 核心功能

- **多目录分批整理**：按拍摄时间从新到旧浏览，批次边界检查相邻图片相似性，减少同组图片被拆开。
- **批量与大图双模式**：无间距正方形网格、拖拽多选、筛选搜索和 Ctrl＋滚轮调节缩略图；大图支持双击缩放、左右拖动切图、相邻图片预载与底部缩略栏，切回批量时自动定位。
- **目录树归类**：侧栏宽度可拖动并记忆，支持数量统计、操作增减及直属内容已整理完的标识；新建目录后自动设为目标，可重命名或确认后移入回收站。
- **浏览位置保留**：批量移动后增量更新图片，定位最后一张移动图片的后继；从其他应用切回时自动刷新目录与内容，保留当前批次和有效选择。
- **裁剪与旋转**：任意角度微调、比例裁剪、一图裁出多个子图；子图继承原拍摄时间并统一留在原目录。单子图支持仅裁剪或覆盖原图，多子图支持仅裁剪或保存后回收原图；关闭裁剪后可移动、复制归类。
- **本地智能裁剪**：可选人像模型生成裁剪框，利用最近最多 100 次成功裁剪记录学习个人偏好，离线运行。
- **视频与 Live 浏览**：封面预览、静音播放及声音开关，兼容支持格式的 iPhone Live Photos 和单文件实况图。
- **主题配色**：单色和双色渐变预设，自定义主色与副色，实时生效并自动保存；渐变只用于较大的主题色块。
- **文件管理与恢复**：移动、复制、单张或批量移入回收站、内容校验、重名避让、移动撤销和未完成操作核对；操作完成后展示成功、失败或部分完成提示；支持清空已结束记录，设置与草稿自动保存。

## 开始使用

安装依赖并构建后，双击 **`Start.cmd`** 打开原生功能版。选择来源目录和目标目录后，可以批量移动图片，或进入大图模式直接裁剪、旋转并导出子图。该入口会执行真实文件操作；`Preview.cmd` 是使用示例数据的独立 UI 演示。

首次使用：

```powershell
git clone https://github.com/kalila-cc/ImageClassifier.git
cd ImageClassifier
```

按[构建环境说明](docs/10-running.md#构建环境)安装 Qt、MinGW 和构建工具，再执行 `./Build.ps1`。测试仅在本地维护和运行；示例图片也不纳入版本控制。仓库不包含本地 SDK、虚拟环境、编译产物、运行日志或个人图库数据库。正式版不依赖示例图片，独立 UI 演示的素材准备见[预览说明](docs/09-ui-preview.md)。

智能裁剪为可选功能，克隆、构建和启动应用均不会自动下载模型。需要时前往 **设置 → 裁剪与智能 → 安装模型**，任务在后台执行，页面显示安装状态；安装完成后可开启智能裁剪。未安装时相关智能控件置灰，浏览、归类和手动裁剪仍可正常使用。安装脚本和模型对接代码随源码提供，模型文件与运行环境由用户按需安装。
